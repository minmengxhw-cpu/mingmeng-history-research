## 1. 民国引文核心原则

民国史 / 中共党史 / 民主党派史 学术论文常见 3 类规范:

1. **《历史研究》体例** (社科院历史所) — 中文为主, 脚注 / 尾注混合
2. **《近代史研究》体例** (社科院近代史所) — 中文为主, 脚注 + 文末参考文献
3. **高校历史系 (北大/清华/南大) 体例** — 类似 Chicago Notes-Bibliography, 民国风

本规范**综合** 3 类, 给出民盟研究最常用版本。

## 2. 5 类资料的标准引文格式

### 2.1 报纸 (《大公报》《光明报》《新华日报》)

**标准格式**:
```
《[报名]》[出版地], [年月日], 第 [N] 版。
```

**例**:
```
《大公报》(天津), 1947 年 11 月 6 日, 第 2 版。
《光明報》(香港), 1941 年 10 月 10 日, 第 1 版。
《新华日报》(重庆), 1946 年 7 月 23 日, 第 3 版。
```

**变体 (期刊名 vs 报名)**:
- 报名用书名号《》
- 副刊 / 副刊名: 《大公报·副刊》

**多版次引用**:
```
《大公报》(天津), 1947 年 11 月 6 日, 第 2、4 版。
```

**转载引用**:
```
《大公报》(天津), 1947 年 11 月 6 日, 第 2 版; 转引自广西民盟官网:
http://www.gxmm.gov.cn/index/index/artical/id/7063.html。
```

### 2.2 期刊 (《民宪》《观察》《民主周刊》)

**标准格式**:
```
《[刊名]》第 [N] 卷第 [M] 期, [年月日], 第 [P] 页。
```

**例**:
```
《民宪》第 1 卷第 9 期, 1944 年 11 月 20 日, 第 1-8 页。
《观察》第 3 卷第 11 期, 1947 年 11 月 1 日, 第 3 页。
《民主周刊》(昆明), 1945 年第 18 期, 第 4-6 页。
```

**期号写法**:
- 民国期刊常用「第 X 期」或「第 X 号」 — 一律用「期」
- 创刊号 / 复刊号: 《民宪》创刊号, 1944 年 5 月 1 日

### 2.3 档案 (NLC / 二史馆 / 馆藏)

**标准格式**:
```
[档案名称], [年月日], [馆藏标识], [馆名]。
```

**例**:
```
《中国民主政团同盟成立启事》, 1941-10-10, NLC 缩微 HKC 951 G91 M, 国家图书馆。
《内政部宣布民盟为非法团体公函》, 1947-10-27, 二史馆 1354 全宗, 中国第二历史档案馆 (南京)。
《清华教授联署声明 (47 位)》, 1947-11-04, 清华大学档案馆。
```

**馆藏标识规范**:
- 全宗号: `1354 全宗` (二史馆) / `HKC 951 G91 M` (NLC 缩微)
- 卷宗号: `第 X 卷`
- 件号 / 缩微号: `件 12` / `Microfilm 1234`

### 2.4 官方汇编 (1983 历史文献 / 民盟文献)

**标准格式**:
```
[编纂机构]: 《[书名]》, [出版地]: [出版社], [年], 第 [P] 页。
```

**例**:
```
中国民主同盟中央委员会: 《中国民主同盟历史文献》, 北京: 文史资料出版社, 1983, 第 156 页。
中国人民政治协商会议全国委员会文史资料研究委员会: 《文史资料选辑》, 北京: 中华书局, 1960, 第 20 辑, 第 35-50 页。
群言出版社: 《中国民主同盟七十年》, 北京: 群言出版社, 2011, 第 88 页。
```

**重印版**:
```
[原出版社]: 《[书名]》, [原出版地]: [原出版社], [原年] 重印, [年]。
例: 文史资料出版社: 《中国民主同盟历史文献》, 北京: 文史资料出版社, 1983 重印, 1985。
```

### 2.5 演讲 / 报告 (闻一多 1946 最后讲演 / 1946 政协)

**标准格式**:
```
[讲演人]: 《[讲题]》, [年月日], [场合], [地点]。
```

**例**:
```
闻一多: 《最后一次讲演》, 1946 年 7 月 15 日, 李公朴先生死难经过报告会, 云南大学至公堂, 昆明。
周恩来: 《在政治协商会议上的报告》, 1946 年 1 月 10 日, 政治协商会议第一次会议, 重庆。
张澜: 《中国需要真正民主政治》, 1943 年 9 月 18 日, 重庆 (民盟中央印发小册子)。
```

**录音 / 速记版本**:
```
闻一多: 《最后一次讲演》(何丽芳 1946-07-15 速记), 1946 年 7 月 21 日 《学生报》第三版首次刊发。
```

## 3. 文内引文格式 (in-text)

| 形式 | 用法 | 例 |
|---|---|---|
| 直接引文 | 「XXX」+ 尾注 | 「中国人民已经觉醒, 反独裁的民主运动, 必将取得最后胜利。」¹ |
| 间接引文 | 文字叙述 + 尾注 | 据张澜 1943 年所述, 民盟中央已就联合政府问题向蒋介石当面提交提案。² |
| 重复引文 | 短注 (作者 + 简称) | 大公报 1947 年 11 月 6 日; 闻一多 1946。 |

**脚注 vs 尾注**:
- **脚注** (footnote): 页底, 适合细密论证
- **尾注** (endnote): 文末, 适合长引文
- 民国史主流: **脚注** (Chicago 风格)

## 4. 4 个边角规则

1. **1949 年前日期**: 一律用民国纪年 (民国 XX 年 X 月 X 日) + 公元对照。
   ```
   民国三十六年十一月六日 (1947-11-06)。
   民国三十年十月十日 (1941-10-10)。
   ```
2. **多版本 / 转载**: 注明原版 + 转载源。
   ```
   原版: 《大公报》(天津), 1947-11-06, 第 2 版。
   转载: 广西民盟官网 http://www.gxmm.gov.cn/.../id/7063.html。
   ```
3. **未刊印档案**: 注明「未刊印」+ 馆藏标识 + cheer-only 接力状态。
   ```
   Service 备忘录 (1944-04-14), 未刊印, FRUS 1944 China v06, d329 附件。
   ```
4. **OCR / 影印件**: 注明 OCR 来源 + 置信度。
   ```
   《民宪》1(9) (NLC 扫描 PDF, OCR 高置信度 + 人工校对, 2026-07)。
   ```
