# 国内史料公开检索长任务：第一批结果

日期：2026-07-18  
编排：Codex  
公开检索执行：MiniMax CLI（mmx）、Grok CLI（grok）

## 执行范围

- 只向 Grok 和 MiniMax 提供公开网页检索任务与公开 URL。
- 没有发送项目数据库、`data/` 原始资料、OCR、PDF、图片缓存、压缩包或本机路径。
- 外部模型的结果只作为候选线索；题名、日期、正文、主办方和 URL 由 Codex 复核后才进入候选 JSONL。

## 结果

1. MiniMax 扩展检索返回了约 20 条线索，主要覆盖国家图书馆民国时期资源、全国报刊索引、抗战文献平台、上海档案数字人文入口和民盟地方站点。
2. 其中若干路径是首页、旧入口或无法在当前公开页面定位到具体条目的地址，未作为具体文献直接入库，保留在后续人工检索清单中。
3. Grok 对已选公开页面完成核验；四条既有民盟上海市委页面和数字报文章继续标记为二次研究/追索索引（L4）。
4. 本轮新增 1 条可复核的公开候选：`刘开渠在上海（1946—1949）`。页面有明确标题、作者、2024-10-12 日期、1946—1949 叙述和民盟上海市委数字报页脚，但没有原始档案案卷号或原报刊期号，因此仍是 L4、待人工复核。

## 判定

本轮没有发现可以直接提升为 L0—L3 的原始文件记录。下一轮应围绕《光明报》《民主》《民主周刊》《沪盟通讯》及上海档案馆的具体案卷/目录号继续检索，优先记录“馆藏机构 + 全宗/目录/案卷/页码”而不是只记录平台首页。
