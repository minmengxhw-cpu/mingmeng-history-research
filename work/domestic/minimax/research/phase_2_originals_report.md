日期：2026-07-18  
执行：Codex；公开检索复核：MiniMax CLI、Grok CLI

## CLI 结果

- MiniMax 在公开入口逐项核验后，未找到《光明报》《民主周刊》《沪盟通讯》或上海档案馆目录的可直链期号/档号级记录，候选条目为 0；这些入口和查档关键词已记录为人工查档线索。

- 本阶段没有向任何外部 CLI 发送项目数据库、扫描件、OCR、PDF、图片缓存、压缩包或本机路径。

## Codex 独立核验到的具体记录

江苏档案信息网的官方“珍档赏析”页面明确标注保管单位为苏州市档案馆，并展示《光明报》苏州解放号外（1949年）的原报图片。页面说明该号外由中国民主同盟苏州支部印刷出版，内容对应1949年4月27日苏州解放。该条已作为 `domestic:DAJS:guangming-suzhou-1949` 写入候选表，暂提 L1、待人工复核，因为公开页没有原件档号。

## 本轮新增：国家档案局专题批量目录

国家档案局“从五一口号到开国大典”专题公开列出1948—1949年多组具体档案条目，包含电报、会议记录、讲话、名单、会议刊物、正式会议文件和影像。已先入库10来源卡、30条L1建议条目，以及32条从官方分页直接提取的LX目录候选。重点覆盖：

- 1948年“五一口号”、毛泽东致李济深/沈钧儒电报、新政协筹备电报；
- 1949年民主人士北上和新政协筹备；
- 1949年9月21—30日政协一届全体会议中的张澜讲话、代表名单、签名册、会议记录、共同纲领、政协组织法、中央人民政府组织法和闭幕词。

L1建议条目均有具体官方条目页和图片入口，但公开页普遍没有完整全宗号、案卷号、页码；LX目录候选只记录索引标题、日期和可追踪链接，必须经过下一轮页面/影像核验后才能升级。

## 链接复核进展

随后对这批国家档案局条目链接进行了只读 HTTP 复核，相关具体页面均返回 200。原先的32条索引候选已升级为 `L1 / item_surrogate / surrogate_online`，但仍保留 `needs_human_review`：HTTP可达不等于影像文字、档号、页码和复制权利已经人工确认。
