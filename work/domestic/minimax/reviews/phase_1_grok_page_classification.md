# MiniMax 对 Grok 四条页面结果的史料等级复核

日期：2026-07-18

MiniMax 的核心判断：四个页面都是后设官方叙述、名录、教育基地介绍或数字报回顾文章，不能仅因发布机构权威就当作同时期一手档案。

MiniMax 建议将四条记录视为 secondary；它给出的 L2 建议不完全符合本项目既定门槛，因为这些网页没有文献汇编书目信息和页码。因此 Codex 最终保留为 `L4 / needs_human_review`，只用于检索词、人物、地点和原始档案追索。

重点追索方向：

- 历史沿革：1945 年筹备、1946 年成立、1947 年被宣布非法对应的会议记录、组织文件和同期报刊；
- 历届领导：选举公告、委员会名单、会议纪要和盟内出版物；
- 教育基地：挂牌决定、批复、场馆原件和同时期地点档案；
- 办公地址变迁：产权、租赁、机关通告和上海市档案馆相关全宗。
