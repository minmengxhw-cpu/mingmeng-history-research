# 高价值国内资料候选对账

日期：2026-08-21

## 本轮边界

本轮只读取候选文件的文件名、PDF 元数据、SHA256、既有 manifest/OCR 状态和来源映射；没有读取正文，没有复制原件，没有写入正式 SQLite，也没有删除任何本地文件。

## 结论

1. 1941-10-10《新华日报》是当前最接近可纳入研究链的候选：日期、SHA、6 页页链和 OCR 均已存在，但仍需要选择性视觉核验；它只能作为同期报刊交叉来源，不能替代成立宣言原刊。
2. 1948 年三中全会扫描件只有 33 页，研究价值高于继续扩大整库规模；先核对版本、日期、封面和文档边界，再做定向 OCR。
3. 1279 页《民主周刊》不能整本 OCR。先建立期号—日期—PDF 页的导航索引，再针对李闻、1946 年政治事件和组织受压材料抽取小批页面。
4. 名为“1945 年临时全国代表大会宣言_公开转录”的 789 页 PDF 经第一页视觉核验，实际是后出《政治协商会议纪实》类编纂材料：编者说明围绕 1946 年政协，末尾署 1988 年 6 月。它降级为 `KEEP_CONTEXT_ONLY`，不再作为 1945 P0 候选，也不再安排整本 OCR。
5. 两份 622 页《中国民主同盟历史文献》SHA 完全相同。只需一个 canonical index identity；另一份保留在本地并记录为 duplicate_storage，不删除。
