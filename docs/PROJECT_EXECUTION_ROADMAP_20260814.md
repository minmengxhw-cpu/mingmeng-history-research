# 民盟国内外统一研究平台执行路线

日期：2026-08-14
适用范围：`mingmeng-history-research` 主线、正式 SQLite、国内资料层、境外 FRUS/档案层及公开研究入口

## 1. 项目目标

把国内史料平台建设成与境外研究平台同等可用的研究系统。

“同等可用”不表示国内外资料数量相同，而表示两侧都具备同一条可复核路径：

```text
研究问题
  -> 统一检索
  -> 专题/时间线
  -> 文献与原件页
  -> 来源等级与证据状态
  -> 页码、档号、哈希、复核记录
  -> 可复核引用
  -> 国内外对读与研究包
```

平台的最终交付物不是“资料文件夹”，而是一个能够回答以下问题的研究工作台：

- 这条判断来自哪一份材料、哪一页？
- 材料由谁、在什么时候形成？
- 它是原件、同期报道、后期汇编还是学术解释？
- 国内外材料是否互相印证或存在冲突？
- 目前还缺哪份原件，下一步到哪里追索？

## 3. 四条并行建设线

### A. 产品线：国内外统一使用体验

统一维护以下入口：

- `/search`：统一全文检索，按平台、时间、人物、组织、资料等级过滤；
- `/research`：按研究问题进入专题；
- `/research/gaps`：显示主证据目标、重要性、候选和下一步动作；
- `/research/packets`：批量进入九个 metadata-only 研究包；
- `/timeline`：按事件、日期和来源层重建时间序列；
- `/doc/<doc_key>`：查看文献及页级来源；
- `/cite/<page_id>`：只为严格门禁页生成引用卡片。

国内结果必须显示来源层和证据状态：

`正式可引用`、`机器可阅`、`原件已锚定·待复核`、`证据待补`。

“专题有入口”和“事件定义的一手原件已闭环”必须分别显示。

公开模式必须继续执行页级授权边界：只有明确允许公开且属于 L0--L3 的国内页面可以展示；研究包不得包含本地路径、正文、OCR、译文或逐字引文。

### B. 证据线：关闭九个国内主证据目标

每个专题采用四层证据链：

1. 主证据：事件定义所需的原件或最接近原件的页级材料；
2. 同期交叉：同期报刊、机关公报、人物函电、地方组织记录；
3. 负向核查：已查过但未发现目标原件的目录、卷册或扫描范围；
4. 待补原件：明确写出重要性、当前状态和下一步动作。

九个 P0 目标按历史结构分批处理：

| 批次 | 专题 | 关闭重点 |
|---|---|---|
| A | 1941 成立 | 独立成立宣言/会议文件、形成者、日期、馆藏档号、版本关系 |
| B | 1946 拒绝参加国民大会 | 民盟正式声明、函电或可定位同期原件 |
| C | 1947 宣布非法与解散 | 1947-10-27 政府文件、1947-11-06 公告及同期原版 |
| D | 1949 新政协 | 筹备会记录、代表发言、完整代表名单、第一届全体会议档案 |
| E | 1944 改组 | 改组会议原件、改名文件、同期刊物和版本关系 |
| F | 1945 一大 | 大会可靠底本、政治报告、宣言、组织规程和缺页关系 |
| G | 1946 旧政协 | 会议日期轴、正式记录、民盟发言和报刊逐条对位 |
| H | 1946 李公朴/闻一多 | 《民主周刊》原版、民盟抗议文件、司法/行政材料 |
| I | 1948 三中全会/五一口号 | 三中全会、五一口号、香港传播拆成独立证据单元 |

### C. 学术线：把高质量研究变成解释层

纳入范围：

- 985 高校教授及正式学术机构成果；
- 中国社会科学院等中央研究机构成果；
- 正式学术期刊论文、专著、学位论文；
- 档案馆目录、馆藏指南和研究史资料。

每条学术记录至少保存：作者、机构、题名、出版物、年份、卷期/章节、稳定入口、版本和哈希（如有）。

学术材料只承担三种作用：解释争议、提供档案线索、连接一手材料。没有稳定全文和页码时只能是 metadata-only，不得升级为一手证据或正式引文。

### D. 工程线：可重算、可回滚、可持续导入

固定流水线：

```text
盘点元数据
  -> 去重与价值筛选
  -> 获取原件并记录权利/哈希
  -> 电子文本直接抽取；扫描件才 OCR
  -> 页级绑定与来源锚定
  -> 机器审计
  -> 人工核验
  -> 研究专题关联
  -> manifest、SQLite、FTS、公开边界验收
```

机器模型可以做盘点、去重、OCR、候选排序、异名发现和报告生成，但不得直接改变正式引用门禁或关闭主证据缺口。

## 4. 每个专题的完成门槛

专题只有同时满足以下条件，才可以标记为 `primary_evidence_status=closed`：

- 至少一条能够定义事件的独立一手原件页级记录；
- 形成者、日期、机构/档号或卷期明确；
- 原件入口、文件 SHA256、页号和页面定位齐全；
- 原图与标题、日期、关键文字经过人工核验；
- 版本关系和缺页情况已经记录；
- 至少一条独立同期交叉材料；
- 与专题研究问题矩阵和研究包建立可回链关系；
- 权利状态允许当前发布范围，或明确保持私有；
- 不依赖机器 OCR、网页标题、后期回顾或学术文章单独完成闭环。

专题“完成”还要通过四类测试：

1. 证据链校验：`validate_topic_evidence_chain.py`；
2. 研究包批量校验：`validate_all_research_packets.py`；
3. 研究问题基准：问题可以进入正确专题并回到页级材料；
4. 公开边界校验：公开入口不输出未授权页面或正文内容。

## 5. 任务节奏

### 第 1 周：基线冻结与 P0 取证准备

- 只认正式库、manifest、当前生成的 parity matrix；
- 为九个开放目标补齐候选来源的主体、日期、档号、入口和权利状态；
- 把目录、转录、后期汇编、同期报道和原件候选分开；
- 先处理 1941、1947、1949 三组最能改变主线完整度的目标；
- 所有模型输出先进入候选/审计区，不写正式引用门禁。

### 第 2—4 周：第一批原件收口

- 对可取得的原件做最小必要下载和页级绑定；
- 电子版直接抽取，只有扫描页才运行 PaddleOCR；
- 建立图片、OCR、源文件和数据库记录之间的哈希链；
- 逐页人工核验题名、日期、页码和研究范围；
- 每关闭一个目标，重新生成专题链、研究包和 parity matrix。

### 第 2 个月：国内外对读与学术层

- 将高质量学术记录按专题、人物、机构和争议点关联；
- 补充国内报刊、机关公报和地方组织的同期交叉层；
- 建立简繁体、异名、旧称和机构沿革词表；
- 用真实问题测试国内外切换、时间线和引用链；
- 严格区分“研究解释成立”和“一手原件闭环成立”。

### 第 3 个月及以后：发布与持续维护

- 每批资料自动生成 manifest、去重报告和来源覆盖报告；
- 正式库、原始资料、OCR 草稿、研究包和公开索引分层存储；
- 发布前执行完整验证；
- 保留数据库快照和代码提交，确保可以回滚；
- 每月复查开放主证据目标和失效链接。

## 6. 任务分工

### 主控与验收

由主控模型负责：

- 选择 P0 目标和证据等级；
- 审核来源真实性、版本关系和权利状态；
- 决定是否进入正式库和引用门禁；
- 运行验收、更新主计划和发布说明。

### 本地模型/CLI

可以负责：

- 批量文件盘点、去重、命名规范化；
- OCR、文本抽取、页序检查；
- 学术元数据整理、异名发现和候选排序；
- 生成不含正文的 manifest、审计报告和任务清单。

不得负责：

- 自动把候选标成正式可引用；
- 用后期叙述替代一手原件；
- 覆盖原始资料或删除低价值资料；
- 把模型摘要当作史实或正式转录。

## 7. 资源与存储原则

- 资料价值优先于资料数量；
- 电子正文优先于重复 OCR；
- 原件和备份永不由自动流程删除；
- 私有正文可以留在本地数据盘，公开站点只发布经过授权的页级元数据和内容；
- 大型 SQLite、图片和 OCR 数据不要全部提交 GitHub；GitHub 保存代码、schema、manifest、研究索引和可恢复说明；
- 任何正式库写入必须先做新文件名的备份，并通过 `PRAGMA integrity_check`、外键、FTS 和来源哈希校验。

## 8. 项目终局

项目达到终局的判据是：

- 国内外均可从同一研究问题入口开始；
- 九个国内核心专题都有清晰的主证据状态，尽可能形成原件闭环；
- 每个重要结论都能回到来源、页码和复核说明；
- 学术解释、同期交叉和一手原件分层显示；
- 研究包可复算、可回链且不泄露正文；
- 新机器可以根据 README、外部数据盘和 manifest 恢复平台；
- 后续新增资料只需按固定流水线进入，不再依赖某个模型的临时记忆。

在达到上述条件前，项目状态只能写成“研究路径可用、核心证据持续收口”，不能宣称国内研究平台已经与国外平台完全等价。
