# PRD：民盟国内一手史料库

> 产品定位：在现有“境外一手档案研究库”基础上，新增“国内史料”一级入口，形成“民盟自述—国内党政机关—国内公共舆论—境外观察”四类视角互证的研究平台。  
> 核心时段：1941—1950；前史延伸至 1936—1940，后续观察带延伸至 1951—1957。  
> 版本：v0.1（规划稿）  
> 日期：2026-07-18

## 一、产品目标

### 1.1 要解决的问题

现有平台的优势是境外档案来源完整、视角差异清楚、可以跨源对位，但对民盟自身如何决策、国内各地组织如何行动、国内社会如何即时记录这些问题，仍缺少系统的原始证据层。

新增国内史料后，平台应回答四类问题：

1. 民盟自己当时说了什么、决定了什么、如何组织和传达；
2. 中共、国民政府及地方党政机关如何观察、联系、限制或回应民盟；
3. 重庆、昆明、上海、南京、北平、成都、广州等关键城市发生了什么；
4. 同一事件在“民盟自述、国内机关、国内报刊、境外档案”中有哪些一致、冲突和信息缺口。

### 1.2 产品成功标准

- 国内材料仍坚持“一手优先”，不把二手研究混入核心档案；
- 每条公开记录都能回答“谁形成、何时形成、原件在哪里、如何取得、能否复核”；
- 国内与境外不是两个孤立网站，而是共享人物、事件、机构、时间线和证据卡片；
- 研究者可以从一件关键事件进入，查看不同责任主体留下的同期记录；
- 原件影像受限时，仍保留目录、档号、获取路径和调档状态，不伪装成已有全文。

## 二、概念边界

“国内史料”不等于“中文材料”，也不等于“目前保存在中国大陆的材料”。系统必须拆开四个维度：

| 维度 | 示例 |
|---|---|
| 形成者 | 民盟中央、中共中央、国民政府、地方政府、报社、个人 |
| 保管地 | 中国大陆、港澳台、海外档案馆或图书馆 |
| 观察视角 | 民盟自述、合作方、打压方、公共舆论、个人见证 |
| 载体层级 | 原档影像、官方影印、正式档案汇编、同期报刊、后期回忆 |

产品入口名称可使用“国内史料”，但数据库中必须使用上述结构化维度，避免把“形成地、保管地、立场、语言”混成一个 `source_platform`。

## 三、目标用户与核心任务

### 3.1 目标用户

- 盟史研究者和地方盟史编写人员；
- 近现代政治史、统一战线史、政协史研究者；
- 需要核对人物、事件和原始引文的编辑人员；
- 平台内部负责搜集、OCR、校订和证据分级的研究人员。

### 3.2 核心任务

1. 按关键事件查找国内原始证据；
2. 按人物查找其同期函电、声明、会议记录和被观察记录；
3. 按城市或地方组织重建活动轨迹；
4. 比较国内文件与 FRUS、CIA、DRNH、Wilson、Hoover、HathiTrust、NewspaperSG 的差异；
5. 生成有原档号、页码和永久来源的引用；
6. 对未数字化材料建立调档清单，并记录获取进度。

## 四、史料收录范围

### 4.1 P0：最高优先级

#### A. 民盟自身原始文件

- 中国民主政团同盟成立文件、纲领、宣言；
- 民盟中央委员会、常务委员会会议记录与决议；
- 第一届全国代表大会及一届三中全会文件；
- 中央通告、组织报告、工作报告、财务或干部名册；
- 各委员会工作纲领、对外声明、内部指示；
- 地方组织成立文件、请示、报告、名册和活动记录；
- 民盟领导人与各方往来函电、备忘录、手稿。

民盟中央“盟史纵览”已公开部分同期纲领，例如《中国民主同盟国内关系委员会工作大纲》和《中国民主同盟现阶段工作纲领》。这类页面可先作为正式来源卡片，但应继续追查纸本出处、原始版本和档案信息。

#### B. 中国第二历史档案馆及国民政府系统档案

- 内政部关于民盟登记、监控、取缔和善后处置的文件；
- 国民政府、行政院、国民党中央、国民参政会、国民大会相关文件；
- 警政、保密、军政系统关于民盟和核心人物的呈报；
- 南京、上海、重庆、昆明等地方机关上报中央的材料；
- 与政协会议、国共和谈、国大、民盟被宣布“非法”有关的原档。

中国第二历史档案馆集中保管民国时期历届中央政权及所属机构档案，是国内线最重要的中央级档案来源。该馆应作为第一批正式调档对象。

#### C. 中共中央、统一战线与政协形成的同期文件

- 中共中央、南方局及统战系统关于民盟的指示、函电、谈话记录；
- 中共与民盟领导人的往来文件；
- 政协会议、国共和谈、新政协筹备会的正式文件；
- 1949 年中国人民政治协商会议第一届全体会议文件、代表名单、发言、提案和组织文件；
- 已正式出版且注明原始档号或成文日期的档案汇编。

这一类必须区分“同期原件”和“后期党史叙述”。只有原始文件、正式会议文件和可核验的档案汇编进入核心证据层。

### 4.2 P1：重要补充

#### D. 地方档案馆

按事件密度而不是行政级别安排优先顺序：

1. 重庆：民盟成立、南方局联系、战时政治活动；
2. 云南／昆明：西南联大、李公朴和闻一多事件、地方盟务；
3. 上海：民盟中央活动、1946—1947 年组织与取缔、1949 年人物处境；
4. 南京／江苏：国民政府中央机关、政协与国大时期活动；
5. 四川／成都：张澜及地方组织；
6. 北平／北京：1949 年新政协筹备与中央迁移；
7. 广东／广州：南方组织、香港与国内联络；
8. 陕西、西南及其他地区：根据人物和事件线索逐步扩展。

每个地方馆先做“目录级侦察”，确认全宗、案卷、开放状态和复制规则，再决定是否批量调档。

#### E. 国内同期报纸与期刊

优先查找能够直接记录民盟声明、会议、采访、地方活动和政府公告的原版影像：

- 《新华日报》《大公报》《文汇报》《新民报》；
- 《光明报》及民主党派相关刊物；
- 重庆、昆明、上海、南京、北平的地方报纸；
- 民盟或关联团体主办的机关刊物、壁报、会议特刊。

国家图书馆的近代文献资源包含民国图书、期刊、报纸和法律文献；“革命历史文献资源库”“民国报纸资源库”可作为国内报刊普查入口。上海图书馆“全国报刊索引”等资源适合做题名、日期和版次定位。受登录、馆内访问或授权限制的资源，公开前台只展示获准公开的影像或元数据。

#### F. 核心人物同期私人文献

- 张澜、罗隆基、章伯钧、沈钧儒、黄炎培、梁漱溟、张君劢、史良、左舜生、张东荪、张申府等人的同期日记、书信、手稿和照片；
- 家属捐赠档案、纪念馆馆藏、大学校史馆或地方文史馆藏；
- 同期形成的口述记录、录音和会议速记。

后期回忆录不作为核心档案；若包含原信、原日记或原文件影印，应把影印件拆分为独立证据记录。

### 4.3 P2：线索层，不进入核心前台

- 后期回忆录、纪念文章、人物传记；
- 学术论文、地方志叙述、盟史综述；
- 新闻网站转载、百科和无原始出处的图文；
- 只有摘引、无法确认原文版本的材料。

这些资料可进入“研究线索库”，用于反查档案，但不得与一手文件混排或生成正式引用。

## 五、证据分级

现有 A／B／C 分级表示“民盟相关度”，国内史料还需要新增独立的“原始性等级”，两者不能合并。

| 原始性 | 定义 | 前台处理 |
|---|---|---|
| L0 原档 | 原件或档案馆数字影像，含完整档号与页码 | 核心展示 |
| L1 官方影印／正式会议文件 | 官方网站或权威机构发布的原文、影印、会议文件 | 核心展示 |
| L2 档案汇编 | 正式出版，标明成文时间、来源或档号 | 展示并标注“汇编本” |
| L3 同期报刊 | 事件发生时形成的新闻、声明、社论、广告或公告 | 展示并标注报刊属性 |
| L4 后期回忆／研究 | 事后叙述或二手研究 | 仅线索库 |
| LX 待核 | 原始性尚未核实 | 内部可见，不公开引用 |

每条文献还需保留现有相关度等级：核心文献、相关文献、人物关联、背景材料、前台不展示。

## 六、信息架构

### 6.1 首页结构

首页顶层形成三个入口：

1. **境外档案**：保留现有七大来源；
2. **国内史料**：新增国内一手史料首页；
3. **多源互证**：按事件、人物、地点查看国内外证据链。

不建议把所有国内档案馆直接铺成首页卡片。国内首页应先展示五个“来源家族”：

- 民盟自身文件；
- 国内党政机关档案；
- 政协与统一战线文件；
- 国内同期报刊；
- 人物与地方组织档案。

### 6.2 新增页面

| 路径建议 | 页面 |
|---|---|
| `/domestic` | 国内史料总入口 |
| `/domestic/sources` | 来源机构与馆藏地图 |
| `/domestic/events` | 国内关键事件时间线 |
| `/domestic/people` | 国内人物同期文件 |
| `/domestic/places` | 重庆、昆明、上海等城市入口 |
| `/domestic/acquisition` | 调档与获取进度 |
| `/domestic/review` | 原始性、OCR、档号和版权复核 |
| `/compare/<event>` | 国内外多源对位页 |

### 6.3 国内首页首屏

- 标题：民盟国内一手史料；
- 副标题：民盟自述、国内机关记录与当时公共舆论；
- 核心数字：已入库原档、已核档号、待调档、关键事件覆盖数；
- 主操作：按事件进入、按来源进入、查看调档清单；
- 方法提示：明确“一手史料、原件优先、二手仅作线索”。

## 七、关键事件首批专题

MVP 不追求大规模，先围绕九个关键事件形成国内外证据闭环：

1. 1941 年中国民主政团同盟成立；
2. 1944 年改组并更名为中国民主同盟；
3. 1945 年第一次全国代表大会；
4. 1946 年政治协商会议；
5. 1946 年民盟拒绝参加国民大会；
6. 1946 年李公朴、闻一多遇害及各方反应；
7. 1947 年民盟被宣布“非法”与组织解散；
8. 1948 年一届三中全会及响应“五一口号”；
9. 1949 年新政协筹备、张澜等北上与第一届全体会议。

每个专题至少包含：

- 1 件民盟自身文件；
- 1 件国内党政或政协文件；
- 1 件同期国内报刊；
- 1 件现有境外档案；
- 1 张证据差异说明卡。

## 八、数据模型

### 8.1 保留现有主表

继续使用 `sources`、`documents`、`pages`、`translations`、`document_classifications` 和 `research_events`，避免为国内史料另建孤立数据库。

### 8.2 建议新增字段

`sources`：

- `repository_code`：档案馆／机构代码；
- `repository_name`：保管机构；
- `holding_region`：大陆／港澳台／海外；
- `provenance_type`：民盟自有／党政机关／报刊／个人／汇编；
- `access_mode`：开放下载／注册访问／馆内访问／线下调档；
- `rights_status`：可公开／仅内部／待核；
- `collection_url`：馆藏或数据库入口。

`documents`：

- `creator`、`recipient`；
- `document_type`：会议记录、决议、函电、呈报、报刊、名册等；
- `archive_fonds`、`archive_series`、`archive_file`、`archive_item`；
- `date_start`、`date_end`、`place_created`；
- `authenticity_level`：L0—LX；
- `verification_status`：待核／元数据已核／影像已核／人工复核；
- `provenance_note`；
- `image_status`、`ocr_status`、`transcription_status`；
- `rights_note`。

### 8.3 建议新增关系表

- `document_relations`：附件、回复、同案卷、重复版本、同事件、引用关系；
- `acquisition_items`：来源、档号、联系人、申请日期、费用、状态、下一步；
- `document_entities`：人物、机构、地点及置信度；
- `source_snapshots`：来源页面快照、获取日期和校验值；
- `editorial_decisions`：收录、降级、隐藏、版权限制及复核记录。

## 九、采集与发布流程

标准流程：

**线索发现 → 建立来源卡 → 查重 → 核实档号／版本 → 获取影像或全文 → 校验文件 → OCR／转录 → 人物事件标注 → 原始性与相关度双分级 → 人工复核 → 前台发布 → 国内外对位**

### 9.1 最低发布门槛

公开文献必须具备：

- 明确形成者和形成日期；
- 可追溯的档号、书刊卷期或官方永久链接；
- 原始性等级；
- 获取日期与文件校验值；
- 权利状态；
- 至少一次人工元数据复核。

没有原件、只有目录的记录可以公开为“待调档”，但不得展示虚构 OCR 或生成正式引文。

### 9.2 文件策略

- 原始扫描件、PDF、图片缓存仍不进入 GitHub；
- GitHub 仅保存代码、元数据清单、公开 OCR、校订报告和采集脚本；
- 大文件保存在本地资料库和备份盘，并记录 SHA256；
- 受限影像只在内部工作台显示，公开页展示目录、档号、来源和利用方式；
- 下载和采集必须遵守档案馆、图书馆与数据库的访问条款。

## 十、MVP 范围

### 10.1 第一阶段：来源普查

- 建立 8—12 个国内来源卡；
- 完成九个关键事件的关键词、人物、机构和地点词表；
- 为中国第二历史档案馆、民盟中央、政协、国家图书馆及五个重点地方馆建立调档清单；
- 形成首批 200 条候选目录，不追求全文。

### 10.2 第二阶段：高价值入库

- 正式入库 80—120 件高价值一手史料；
- 九个关键事件均形成至少一组国内外对位；
- 公开文献 100% 有来源路径，60% 以上达到 L0／L1；
- 完成人工校订的题名、日期、形成者、档号和页码；
- 上线 `/domestic` 与国内检索筛选。

### 10.3 第三阶段：地方与人物扩展

- 扩展重庆、昆明、上海、南京、成都、北平、广州七地；
- 建立核心人物同期函电索引；
- 把国内报刊与机关档案按日对齐；
- 支持从一件境外档案反查同日国内记录。

## 十一、衡量指标

- 原档或官方原文比例；
- 有完整档号／卷期比例；
- 人工复核完成率；
- 九个关键事件的多源覆盖率；
- 国内文献与境外文献建立关系的比例；
- 待调档转为已获取的周期；
- OCR 字符准确率与人工修订率；
- 因版权或来源不明被限制公开的记录数；
- 正式引用中回到原件而非摘要的比例。

不把“文献总量”作为首要指标。第一阶段宁可 100 件高质量原档，也不要 1 万条无法核验的网络材料。

## 十二、风险与控制

| 风险 | 控制措施 |
|---|---|
| 国内／境外按立场简单二分 | 使用形成者、保管地、视角和载体四维元数据 |
| 官方网站材料被误当原档 | 强制设置 L0—LX 原始性等级 |
| 汇编本丢失档号或删节 | 记录版本、编辑机构、页码和原始出处 |
| OCR 对繁体、旧字、人名误识别 | 原图与转录并列，核心文献人工校订 |
| 登录资源或馆内资源无法公开 | 公开元数据，影像留内部，记录利用条件 |
| 扫描件误传 GitHub | 延续大文件排除规则和提交前检查 |
| 后期叙述混入同期证据 | L4 只进线索库，不参与核心检索和引用 |
| 不同来源重复收录 | 用档号、标题、日期、首句和文件哈希联合查重 |

## 十四、验收标准

MVP 达到以下条件才视为可上线：

1. `/domestic` 页面与现有境外平台入口并列；
2. 国内史料可按来源家族、人物、地点、事件、原始性和相关度筛选；
3. 每条公开文献显示形成者、保管机构、档号／卷期、原始性、权利状态和获取路径；
4. 九个关键事件至少各有一组国内外对位证据；
5. L4 二手材料不会出现在核心文献列表；
6. 受限影像不会通过公开 URL 泄露；
7. 国内文献可以沿用现有引用卡片、时间线、人物页和证据卡片；
8. 收录、隐藏和降级都有可追溯的编辑记录。
