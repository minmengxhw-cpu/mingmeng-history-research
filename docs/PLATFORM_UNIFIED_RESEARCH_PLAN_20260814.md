# 国内外统一研究平台推进方案

日期：2026-08-14

## 目标

把国内史料层建设成与境外档案层同等可用的研究入口：研究者可以从一个问题进入，检索国内外资料，区分形成者与证据等级，打开原件页，看到页码和来源链，并导出可复核引用。

这里的“同等可用”不等于国内外资料数量相同，也不等于把所有国内网页、后期回顾和机器 OCR 都升级成一手资料。它指的是两侧拥有同样完整的研究路径和同样严格的证据门禁。

## 当前基线

截至本方案日期，正式数据库中有 1,403 篇文档、6,237 个页面，其中国内 542 篇；国内有 5,166/5,167 个页面具备本地源文件和 SHA256 锚定，严格人工可引用页 124 页，9 个专题已有国内外导航关联。数据库完整性、外键、页面与全文索引、来源文件哈希均已通过当前 manifest 验证。

这些数字描述的是工程状态，不代表 542 篇国内文档都已完成逐页人工核验。机器可阅、原件已锚定、人工可引用和待调档必须继续分层。

## 统一产品模型

### 1. 一个研究入口

- `/search`：国内外统一全文检索，可按平台、年份、人物和资料分级筛选。
- `/research`：按研究问题进入国内外专题对读。
- `/timeline`：按日期和平台重建事件序列。
- `/doc/<doc_key>`：回到文献及页面级原文、OCR 和来源。
- `/cite/<page_id>`：只对满足门禁的页面生成正式摘录卡片。

统一入口中，国内命中必须显示“国内史料”标识和页级状态：`正式可引用`、`机器可阅`、`原件已锚定·待复核` 或 `证据待补`。不能让用户从搜索结果误以为 OCR 草稿已经等于正式引文。

### 2. 四个资料层

| 层级 | 可做什么 | 不可做什么 |
|---|---|---|
| 原件层 | 保存 PDF、图片、网页快照、来源 URL、获取时间、SHA256 | 不因入库而改变原件 |
| 检索层 | 抽取正文、OCR、繁简体检索、关键词命中 | 不把机器命中写成史实 |
| 证据层 | 绑定文献、页码、原图、哈希、复核说明 | 不用候选 accepted 代替页级审核 |
| 研究层 | 时间线、人物/组织/地点关系、国内外对读、学术解释 | 不让学术研究替代一手材料 |

## 资料建设顺序

### P0：核心一手证据

优先补齐：

1. 1941 年成立文件、纲领、宣言和民盟自身早期组织材料；
2. 1945 年临时全国代表大会及民盟一大文件；
3. 1946 年政协、国民大会争议和地方组织同期材料；
4. 1947 年 10 月政府文件、11 月民盟总部公告及同期报刊整版；
5. 1948—1949 年三中全会、五一口号、新政协和民盟组织转型材料。

每一项必须记录形成者、形成日期、保管机构、档号/卷期、原件入口、权利状态和页级定位。无法取得原件时保留为调档任务，不伪装成已完成证据。

### P1：同期交叉材料

把国内官方公报、同期报刊、地方组织材料和人物公开函电作为交叉验证层。它们可以补充事件过程，但必须标明是原件、官方转载、报刊报道还是后期整理。

### P2：高质量学术研究

纳入中央研究机构、985 高校和正式学术期刊的论文、专著、档案指南及学位论文。学术层负责：

- 提供研究史与争议解释；
- 提供档案号、馆藏线索和人名异名；
- 帮助发现国内一手材料；
- 与一手页建立“解释—原件”链接。

学术条目没有稳定全文、页码/章节、版本和哈希时，只能是 metadata-only 或解释层候选，不能进入正式一手引用。

## 每批资料的固定流水线

1. 元数据盘点：先去重、判定主题、形成者、时间和资料类型；
2. 价值筛选：区分核心一手、同期交叉、学术解释、背景线索和低价值重复；
3. 原件获取：记录稳定入口、文件大小、SHA256、版权/访问状态；
4. 文本处理：电子正文优先直接抽取，只有扫描件才使用 PaddleOCR；
5. 页级绑定：保留 PDF 页号、实体页号、页图路径、OCR 引擎和置信度；
6. 机器审计：检查空页、页序、文本长度、来源哈希、路径逃逸和 FTS 对齐；
7. 人工核验：对照原图，确认题名、日期、页码和关键文字，写入复核说明；
8. 研究关联：将合格页面保守地关联到事件、人物、组织和地点；
9. 发布验收：更新 manifest，跑完整测试，确认 SQLite integrity、外键、来源文件和引用门禁。

## 分阶段目标

### 阶段一：统一使用体验

- 国内外共用搜索、专题、时间线和文献详情入口；
- 搜索结果显示国内来源层和页级证据状态；
- 国内专题详情页同时展示候选、已入库页面、境外命中、学术解释和缺口；
- 公开模式不泄露本地私有正文或未授权资料。

验收：真实数据库下 `/search?platform=domestic`、`/research`、`/timeline?platform=domestic`、专题详情和文献详情均返回 200；结果能回到页面级来源；无证据状态的页面不能出现“正式可引用”。

### 阶段二：核心证据收口

- 九个专题各有明确 P0 原件目标；
- 1941、1945、1946、1947 四个关键时期形成页级证据包；
- 1947 年政府文件和民盟总部公告缺口单独显示，不被后期文章覆盖；
- 公开报刊剪报只作为同期报道或线索，不冒充政府原件。

验收：每个核心事件至少有一条可复核主证据，且有一条独立交叉材料；缺口页显示调档状态和下一步动作。

### 阶段三：研究关系与学术层

- 建立人物、组织、地点、事件和文献关系；
- 支持简繁体、旧译名、异名和机构沿革；
- 学术条目与国内一手页面形成可点击的解释—原件链；
- 对重复版本进行关系标注而不是重复计数。

验收：用 30—50 个真实研究问题测试，检索结果能在国内外之间切换，且每个结论都能看到证据边界。

### 阶段四：长期治理与发布

- 每批导入自动生成 manifest 和审计报告；
- 数据、原件、OCR、研究草稿和公开索引分层存放；
- 公开站点只发布允许公开的元数据和内容；
- 每次发布保留可回滚的代码提交和数据快照。

验收：新机器可按 README 恢复代码、配置外部数据盘并通过 manifest 验证；发布测试不依赖未记录的本地状态。

## 当前明确不做的事

- 不为“数量增长”批量 OCR 已有电子正文；
- 不删除本地原件、缓存、备份或 OCR 草稿；
- 不把后期官方回顾、学术文章、网页标题或低清剪报当作政府原始公文；
- 不让 Grok、MiniMax 或其他模型直接改变正式引用门禁；它们可以做盘点、OCR、去重和候选整理，正式验收必须经过可重算审计。

## 终局定义

当研究者可以对同一个问题同时查看民盟自身材料、国内机关/报刊、学术解释和境外档案，并且每条记录都明确“原件在哪里、页码是什么、谁审核过、还能缺什么”时，国内平台才真正达到与境外平台同等的研究价值。
