# 国内外统一研究平台推进方案

日期：2026-08-14

## 目标

把国内史料层建设成与境外档案层同等可用的研究入口：研究者可以从一个问题进入，检索国内外资料，区分形成者与证据等级，打开原件页，看到页码和来源链，并导出可复核引用。

这里的“同等可用”不等于国内外资料数量相同，也不等于把所有国内网页、后期回顾和机器 OCR 都升级成一手资料。它指的是两侧拥有同样完整的研究路径和同样严格的证据门禁。

专题详情页进一步把国内证据固定为四层链：`主证据（页级）`、`同期交叉`、`负向核查` 和 `仍待补原件`。四层之间不互相替代，且每一条页级记录都必须能回到正式库的文献页；这使“国内已经能研究什么”和“事件定义还缺什么”同时可见。

## 当前基线

截至 2026-08-14（Asia/Shanghai），正式数据库中有 1,403 篇文档、6,237 个页面，其中国内 542 篇；国内有 5,166/5,167 个页面具备本地源文件和 SHA256 锚定，严格人工可引用页 201 页，国内专题事件索引为 572 条关联行、558 个不同页面，9 个专题已有国内外导航关联。数据库完整性、外键、页面与全文索引、639 个来源文件及其 SHA256 均已通过当前 manifest 验证。

## 统一产品模型

### 1. 一个研究入口

- `/search`：国内外统一全文检索，可按平台、年份、人物和资料分级筛选。
- `/research`：按研究问题进入国内外专题对读。
- `/research/gaps`：按九个专题列出仍开放的主证据目标、重要性、下一步和候选记录，作为国内资料收口看板。
- `/research/packets`：九个专题研究包的批量入口，显示证据链、专题回接页、严格门禁和开放原件目标；专题详情和研究包均能回到同一页级来源集合。
- `/timeline`：按日期和平台重建事件序列。
- `/doc/<doc_key>`：回到文献及页面级原文、OCR 和来源。
- `/cite/<page_id>`：只对满足门禁的页面生成正式摘录卡片；国内页面使用独立的中文页级引用格式，带来源版本、PDF/物理/印刷页、页级 URL、文件 SHA256 和人工复核说明，不套用境外 FRUS 书目模板。
- `/research/<event_id>/packet`：导出一个元数据-only 专题研究包；它把研究问题、国内外对读、四层证据链、学术解释候选、页级 provenance 和开放原件目标放在一起，并逐页回链到专题页、原文页和引用门禁。

统一入口中，国内命中必须显示“国内史料”标识和页级状态：`正式可引用`、`机器可阅`、`原件已锚定·待复核` 或 `证据待补`。专题入口还必须分开显示“研究导航可用”和“一手证据闭环”两个状态，不能让用户从搜索结果或专题入口误以为 OCR 草稿、后期汇编或对读入口已经等于事件定义原件。

公开模式的专题页也必须遵守同一条页级授权边界：`/research`、专题详情、`/research/packets`、研究包 JSON 和专题事件索引只能展示明确 `rights_status=public` 且为 L0--L3 的国内文档页。共享证据链和研究问题矩阵不得因为“已经被专题关联”而绕过这一门禁；未授权页在公开模式中直接省略，研究包继续保持 metadata-only，不暴露本地路径、正文、OCR、译文或逐字引文。

### 2. 四个资料层

| 层级 | 可做什么 | 不可做什么 |
|---|---|---|
| 原件层 | 保存 PDF、图片、网页快照、来源 URL、获取时间、SHA256 | 不因入库而改变原件 |
| 检索层 | 抽取正文、OCR、繁简体检索、关键词命中 | 不把机器命中写成史实 |
| 证据层 | 绑定文献、页码、原图、哈希、复核说明 | 不用候选 accepted 代替页级审核 |
| 研究层 | 时间线、人物/组织/地点关系、国内外对读、学术解释 | 不让学术研究替代一手材料 |

## 资料建设顺序

### P0：核心一手证据

优先补齐：

1. 1941 年成立文件、纲领、宣言和民盟自身早期组织材料；
2. 1945 年临时全国代表大会及民盟一大文件；
3. 1946 年政协、国民大会争议和地方组织同期材料；
4. 1947 年 10 月政府文件、11 月民盟总部公告及同期报刊整版；
5. 1948—1949 年三中全会、五一口号、新政协和民盟组织转型材料。

每一项必须记录形成者、形成日期、保管机构、档号/卷期、原件入口、权利状态和页级定位。无法取得原件时保留为调档任务，不伪装成已完成证据。

### P1：同期交叉材料

把国内官方公报、同期报刊、地方组织材料和人物公开函电作为交叉验证层。它们可以补充事件过程，但必须标明是原件、官方转载、报刊报道还是后期整理。

### P2：高质量学术研究

纳入中央研究机构、985 高校和正式学术期刊的论文、专著、档案指南及学位论文。学术层负责：

- 提供研究史与争议解释；
- 提供档案号、馆藏线索和人名异名；
- 帮助发现国内一手材料；
- 与一手页建立“解释—原件”链接。

学术条目没有稳定全文、页码/章节、版本和哈希时，只能是 metadata-only 或解释层候选，不能进入正式一手引用。

## 每批资料的固定流水线

1. 元数据盘点：先去重、判定主题、形成者、时间和资料类型；
2. 价值筛选：区分核心一手、同期交叉、学术解释、背景线索和低价值重复；
3. 原件获取：记录稳定入口、文件大小、SHA256、版权/访问状态；
4. 文本处理：电子正文优先直接抽取，只有扫描件才使用 PaddleOCR；
5. 页级绑定：保留 PDF 页号、实体页号、页图路径、OCR 引擎和置信度；
6. 机器审计：检查空页、页序、文本长度、来源哈希、路径逃逸和 FTS 对齐；
7. 人工核验：对照原图，确认题名、日期、页码和关键文字，写入复核说明；
8. 研究关联：将合格页面保守地关联到事件、人物、组织和地点；
9. 发布验收：更新 manifest，跑完整测试，确认 SQLite integrity、外键、来源文件和引用门禁。

## 分阶段目标

### 阶段一：统一使用体验

- 国内外共用搜索、专题、时间线和文献详情入口；
- 搜索结果显示国内来源层和页级证据状态；
- 国内专题详情页同时展示候选、已入库页面、境外命中、学术解释和缺口；
- 国内专题详情页展示四层证据链，并从页级记录回到原文、页码和复核门禁；
- 公开模式不泄露本地私有正文或未授权资料。

验收：真实数据库下 `/search?platform=domestic`、`/research`、`/timeline?platform=domestic`、专题详情和文献详情均返回 200；结果能回到页面级来源；无证据状态的页面不能出现“正式可引用”；专题的导航状态和一手闭环状态必须独立呈现。

公开模式额外验收：`/research?public=1`、公开专题详情、`/research/packets?public=1` 和公开 `packet.json` 均返回 200；专题事件样本、四层证据链和矩阵页级链接中不得出现未通过国内公开文档谓词的页面。

研究包验收：研究包 JSON 必须包含数据库 SHA256、页级来源 SHA256、复核状态和 `review_scope`；每一条页级记录都能回到 `/doc/<doc_key>?page_id=...` 与 `/cite/<page_id>`；`body_text_included`、`ocr_text_included`、`translation_text_included` 和 `verbatim_quote_included` 必须为 false。研究包是研究编排和引用导航，不是正文复制或自动生成引文。批量验收使用 `scripts/domestic/validate_all_research_packets.py`，要求九个包均能重建、页级记录均解析、正文边界保持关闭，并分别报告证据链页、专题事件回接页和候选回接页。专题事件索引页也只导出页级元数据、provenance 和回链，不导出 `pages.text` 或事件摘要正文。

### 阶段二：核心证据收口

- 九个专题各有明确 P0 原件目标；
- `/research/gaps` 将每个开放目标绑定到研究问题、候选记录和下一步动作；
- 1941、1945、1946、1947 四个关键时期形成页级证据包；
- 1947 年政府文件和民盟总部公告缺口单独显示，不被后期文章覆盖；
- 公开报刊剪报只作为同期报道或线索，不冒充政府原件。

验收：每个核心事件至少有一条可复核主证据，且有一条独立交叉材料；缺口页显示调档状态和下一步动作。

### 阶段三：研究关系与学术层

- 建立人物、组织、地点、事件和文献关系；
- 支持简繁体、旧译名、异名和机构沿革；
- 学术条目与国内一手页面形成可点击的解释—原件链；
- 对重复版本进行关系标注而不是重复计数。

验收：用 30—50 个真实研究问题测试，检索结果能在国内外之间切换，且每个结论都能看到证据边界。

### 阶段四：长期治理与发布

- 每批导入自动生成 manifest 和审计报告；
- 数据、原件、OCR、研究草稿和公开索引分层存放；
- 公开站点只发布允许公开的元数据和内容；
- 每次发布保留可回滚的代码提交和数据快照。

验收：新机器可按 README 恢复代码、配置外部数据盘并通过 manifest 验证；发布测试不依赖未记录的本地状态。

## 当前明确不做的事

- 不为“数量增长”批量 OCR 已有电子正文；
- 不删除本地原件、缓存、备份或 OCR 草稿；
- 不把后期官方回顾、学术文章、网页标题或低清剪报当作政府原始公文；
- 不让 Grok、MiniMax 或其他模型直接改变正式引用门禁；它们可以做盘点、OCR、去重和候选整理，正式验收必须经过可重算审计。

## 终局定义

当研究者可以对同一个问题同时查看民盟自身材料、国内机关/报刊、学术解释和境外档案，并且每条记录都明确“原件在哪里、页码是什么、谁审核过、还能缺什么”时，国内平台才真正达到与境外平台同等的研究价值。

## 当前状态口径（2026-08-14）

当前九个专题均已具备国内候选、境外入口、学术解释入口和至少一页严格页级导航，因此是 `navigation_ready=9`；但九个专题的事件定义原件仍各有缺口，当前均为 `primary_evidence_status=partial`，所以严格 `research_ready=0`。这不是平台退步，而是把“能找到研究路径”和“关键一手来源已经闭环”分成两个可审计指标。1946 年拒参专题已经有新七号、新八号和新十一号的同期机关报页级入口，但三者均按“同期政治表达”使用，不替代正式组织文件。

四层证据链当前为 `evidence_chain_ready=9`：共 120 个页级条目，其中 112 个满足正式引用门禁；同时保留 9 个待补原件目标。1949 新政协专题目前有 53 个来源地图页级记录，其中 17 个已完成视觉复核并进入严格引用，36 个仅作为正式库已绑定页面的 `navigation_only` 路径；它们覆盖代表名单、代表签名册、北上邀请电报、筹备会小组工作档案、第二次全体会议材料、开幕讲话、主席团名单和第一届全体会议日程页。这些页面可支持页级导航和有限事实核对，但不等于完整会议档案。1948 三中全会/五一口号专题新增 7 个中央档案公开扫描页级锚点（正式页 `20665`—`20671`），同样只支持明确的页身份、版本和复核范围。1944 改组专题另有 4 个官方汇编页级锚点，1945 大会专题已有 33 个官方汇编/文献页级锚点，1946 拒参专题已有 6 个《光明報》同期页级锚点及 1 个官方汇编重刊页 `19000`；1946 李闻专题新增 3 个官方汇编重刊页级锚点，但仍不替代独立抗议文件、原始刊物或司法/行政材料。上述页面均不替代改组会议、成立原件、正式拒参声明、政协完整会议档案或政府解散公文。1947 专题新增 6 个国家图书馆公开扫描同期报刊页级交叉入口，仍不替代政府公函或民盟公告原件。`/research/gaps` 将这 9 个目标转换为可执行的收口看板；`scripts/domestic/validate_topic_evidence_chain.py` 除了校验专题覆盖、页号、文档键、国内来源和 `page_provenance` 门禁，还要求每个开放目标写明重要性和下一步动作，parity 矩阵及完成监控均使用这项检查。

本轮将 1945 年民盟第一次全国代表大会作为首个专题研究包样板：40/40 条页级证据链记录可回到正式库，40/40 条严格页级链条通过引用门禁，包内同时保留大会原件/版本关系的开放缺口；研究包不复制正文、OCR 或译文。现已扩展为九专题批量研究包索引和批量验收；每个包同时报告“证据链页”“专题事件索引回接页”和“候选资料回接页”，避免将不同入口的页数混为一谈。由于研究包按当前 staging 数据盘动态生成，干净 checkout 需要按 README 配置 `MINGMENG_STAGING_DB` 才能恢复完整学术解释层；没有 staging 时仍可从正式 SQLite 回退到已入库学术全文元数据。该样板在当前本机 staging 数据盘上包含 6 条学术解释候选；若 staging 未挂载，学术候选数会按可用数据自然降级，但不会影响页级证据门禁。

下一阶段不以继续增加候选数量为主要目标，而以九个专题的 `primary_evidence_gap` 逐项关闭为目标；每次关闭必须同时补齐原件入口、形成者/日期、档号或卷期、页级定位、来源哈希、权利状态和人工复核记录。

## 研究问题基准（2026-08-14）

### 研究问题—证据矩阵（2026-08-14）

为让国内专题具备与境外专题相同的“打开即能研究”体验，新增
`data/domestic/topic_research_matrix.json`。九个国内专题各登记 4 个子问题，共 36 个；每个子问题明确当前状态、已登记页级入口、证据范围、不能推出的结论和下一步调档动作。矩阵只引用 `topic_evidence_chain.json` 中已有的页号和开放目标，不读取或复制正文、OCR、译文或逐字引文。

专题详情页和元数据-only 研究包均展示该矩阵。它解决的是研究路径问题：研究者可以先按子问题选择页级材料，再回到 `/cite/<page_id>` 检查该页的人工复核范围；它不改变 `primary_evidence_status`，不把报刊、汇编、目录页或机器文本自动升级为事件定义的一手原件。当前仍为 9/9 `research_ready=0`，原因仍是九个专题的关键原件缺口，而不是导航缺失。

本轮进一步新增 `data/domestic/topic_foreign_crosswalk.json`，为 36 个子问题逐项声明境外对读关系：直接相关、并行记录、背景对读或暂无同命题境外专题。专题页和研究包会同时显示境外入口、机器命中页数及关系边界；没有对应专题的地方明确显示缺口，不用境外机器命中冒充国内证据，也不把境外背景记录当作国内原件。
