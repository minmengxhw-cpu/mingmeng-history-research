# 国内专题一手目标子单元审计

更新时间：2026-08-22
结论：`bounded_units_available / primary_targets_open`

## 1. 使用方式

九个专题目前都有页级材料，但每个专题仍有一个更大的开放一手目标。两者必须分开显示：

- `bounded_unit_ready`：已有来源、页身份、SHA256 和引用边界，可以回答范围受限的问题；
- `primary_target_open`：原件、档号、完整版本链、完整档案或复制权利仍未闭合；
- `research_ready`：只有主目标关闭后才允许使用，不能由页数、OCR 或学术文章数量自动推导。

以下两组均已经完成页身份、连续范围和 SHA256 登记，可用于有边界的“邀请/组织指示/民主人士回应”研究：

## 4. 研究包显示规则

研究包可以直接使用上述 `bounded_unit_ready` 材料，但每条结论必须同时显示：

1. 来源标题和机构入口；
2. 页 ID、物理页/印刷页关系和 SHA256；
3. 该页能证明的范围；
4. 尚未取得的原件、全文、档号或权利；
5. 不得由该页外推的结论。

`primary_target_open` 只在取得独立原件、版本关系、页级 provenance 和权利/公开边界后才可关闭。OCR 只作为检索衍生层，不改变上述状态。
