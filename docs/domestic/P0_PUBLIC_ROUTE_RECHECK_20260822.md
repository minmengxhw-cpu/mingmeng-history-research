# 1947 年 P0 原件公开路线复查

复查日期：2026-08-22  
范围：1947-10-27 政府宣布民盟为非法团体的行政原件；1947-11-06 民盟总部解散公告/正式声明原始底本。  
边界：只做公开网页、馆藏入口和已登记路线的元数据复查；不读取授权账号正文，不下载私有原件，不写正式 SQLite。

## 结论

本轮没有发现同时满足以下条件的公开数字原件：

- 可确认是目标行政文书或民盟总部原始公告；
- 有机构、档号/记录号、日期和版本关系；
- 有可复现的页级影像或稳定复制件入口。

因此两个 P0 目标仍保持：

```text
research_content_status = OPEN_PRIMARY_GAPS
primary_evidence_closed = false
```

“没有找到公开原件”不等于“原件不存在”。本轮结果只改变路线审计状态，不改变历史事实判断。

## 命中路线的分层

### 1. 同期报道和后期说明：交叉层，不是目标原件

广西民盟专题页提到 1947-11-06 张澜以民盟中央主席名义发表解散公告，并展示/说明《大公报》等同期报道。该页可帮助确认检索词、报刊标题和日期关系，但没有提供目标公告的独立档号、原始底本关系或完整可复核档案页，因此继续作为导航/交叉路线。

入口：

- <https://www.gxmm.gov.cn/index/index/artical/id/7063>

项目已有的天津、上海、汉口版《大公报》页级影像继续保留为同期报道证据；不能升级为政府公函或民盟总部公告。

### 2. 上海档案馆：最重要的行政链调档路线

上海档案馆的数字人文平台公开说明其馆藏包含 1945—1949 年国民政府时期上海党政军警机关档案及社会团体档案，但本轮未在公开检索结果中取得 `上档6-5-1216` 或 `上档Q6-5-947` 的目标原件页面。

公开的 [J-STAGE《アジア研究》论文 PDF](https://www.jstage.jst.go.jp/article/asianstudies/49/3/49_38/_pdf) 第 13 页注 61 提供了更精确的路线语义：`上档6-5-1216` 所引文书题名为“奉令為宣布民主民盟為非法団体転令遵照由”，文书日期为 1947-11-02；论文另将上海市政府布告/执行节点记为 1947-11-11。该论文脚注只证明学者引用了档号和题名，不是档案原件影像；两个日期必须分别登记，不能合并成“已取得 10 月 27 日政府公函”。

入口：

- <https://dh.archives.sh.cn/>
- [上海市档案馆数字档案公共查阅系统](https://www.shda.gov.cn/daly/szdacypt/)
- `上档6-5-1216`：民盟非法化转令/地方执行链
- `上档Q6-5-947`：市参议会公函、上海市政府训令线索

两案卷只能通过档案馆目录/申请实际核验；不能把论文脚注或平台馆藏概览写成原件已取得。

### 3. 国史馆 DRNH：官方目录/锁定影像路线

已登记的 DRNH 件号仍是官方数字影像互证路线，但当前访客会话只确认目录与锁定状态，没有取得原始字节、下载许可或页级正文：

- `002-020400-00012-067`
- `002-060100-00229-023`
- `002-020400-00011-053`
- `002-080200-00537-081`
- `002-080200-00537-095`

当前门禁继续保持 `official_viewer_locked`、`download_available=false`、`citation_ready=false`。

### 4. 民盟历史文献全媒体数据库：授权浏览器路线

这是目前最可能直接取得 1947-11-06 总部公告或相关正文的路线，但必须在已授权浏览器会话中实际下载并记录：

- 记录号/详情页 URL；
- 文种、题名和形成日期；
- 原文件名、字节数、SHA256、页数；
- 复制/公开许可；
- 页身份、相邻页和版本关系。

入口：<http://www.minmeng1941.cn/WEB/INDEX.html>

在文件进入 `data/domestic/raw/authorized_originals/incoming/` 之前，不进行正文 OCR、不写正式 SQLite，也不改变主证据状态。

## 下一步最小动作

1. 用户授权浏览器中优先检索并下载 1947-11-06 总部解散公告/正式声明；
2. 以 `上档6-5-1216` 和 `上档Q6-5-947` 向上海档案馆申请目录、文号、全文或可复制页；
3. 并行复核 DRNH 五个件号的可下载状态；
4. 任一原件到达后运行：

```bash
python3 scripts/domestic/prepare_authorized_original_intake.py
```

5. 只有文件哈希、页数、来源/权利字段、页身份复核和版本关系齐全后，才进入 staging dry-run。

## 不重复执行的工作

- 不重复下载 1983 年汇编；
