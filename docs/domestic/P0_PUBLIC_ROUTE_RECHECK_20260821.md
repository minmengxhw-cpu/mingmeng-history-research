本轮只做公开网页和馆藏入口核查，不下载正文原件、不读取授权账号、不写正式 SQLite。

### 证据分级

上述两条路线可以证明“原刊有明确馆藏和可执行调取路径”，不能证明已经取得 `1941-10-10` 原刊影像、版次、页码或复制授权。因此继续保持：

```text
primary_evidence_closed = false
research_ready = false
```

仍需通过 HKU 调取或用户授权复制，随后完成馆藏标识、页界、图像 SHA-256、人工视觉复核和与 1946 汇编/后期转录的版本对读。

## 1947 年非法化与总部解散

本轮公开搜索命中的材料仍分为三类：

1. 同期报刊数字转录或报面入口：可作为交叉报道，不能替代 1947-10-27 内政部公函或 1947-11-06 总部解散公告原件；
2. 民盟地方组织、政协和党史机构的后期叙述：可用于出处和时间线导航，不进入主证据闭环；
3. 其他日期恰好相同但主题无关的馆藏条目：作为负向检索结果，不入库。

### 新增一条官方转载图像路线（仍非原件闭环）

九三学社中央专题页[《纪念中共中央发布五一口号70周年》](https://www.93.gov.cn/html/93gov/zt/wykh2018/xhxc/180417164558481095.html)在正文中标注一幅“1947年10月27日……图为当时报纸报道的消息”的图像，并给出内政部发言人指责民盟、要求严加取缔的文字说明。该页和嵌入图像可作为公开追索线索，但当前页面正文没有提供报纸名称、版次、页码、原始馆藏档号或图像来源说明，因此登记为：

```text
route_status = OFFICIAL_CURATED_REPRODUCTION
evidence_level = L1
primary_evidence_closed = false
```

嵌入图像入口：
`https://www.93.gov.cn/11002/upload/webcms/content/image/2018/04/17/16_15_29_560_91431_4.webp.jpg`

后续只做来源识别和可复现性核验：确认图像上的报头、日期、版次，再回到国家图书馆/报刊数据库或馆藏目录寻找原刊；不能把九三学社专题页的转载图像直接当作 1947-10-27 内政部公函原件。

### 日期与图像身份的拆分核验

继续检索后，广西民盟的后期专题叙述将时间线拆为：10 月 27 日内政部发言人宣布民盟为“非法团体”，10 月 28 日中央社发表《政府宣布民盟非法》的声明，并未提供该报纸图像的原刊扫描、报头、版次或档号：

- [《大公报》和《观察》对民盟被迫解散的不同反应](https://www.gxmm.gov.cn/index/index/artical/id/7063)

因此本项目将图像的“页面图注日期” `1947-10-27` 与“可能相关的中央社声明日期” `1947-10-28` 分开保存，`identity_status=unresolved`。后者只是后期叙述中的追索线索，不能反向证明转载图像就是 10 月 28 日的《中央日报》或中央社原刊；当前仍不新增正式来源、页级记录或 `citation_ready` 记录。

因此仍没有发现同时具备独立原件身份、档号/版本关系和页级 provenance 的目标行政文件。现有 1947-11-04/06《大剛報》原刊扫描和《觀察》原刊继续保留为同期交叉材料，不提升为行政或组织原件。

## 处理决定

- 不新增重复 OCR；
- 不把馆藏表、剪报索引、后期转录或搜索摘要标成 `primary`、`citation_ready` 或 `primary_evidence_closed`；
- 1941 与 1947 两个 P0 目标继续保持 `OPEN`；
- 下一步最小闭环仍是：取得授权原件/复制件 → 生成 manifest → 页级身份核验 → 定向 OCR draft → 人工复核 → 版本关系 → 统一门禁。
