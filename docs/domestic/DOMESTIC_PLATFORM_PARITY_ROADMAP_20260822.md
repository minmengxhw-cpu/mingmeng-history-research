# 国内民盟研究平台 parity 路线图

更新时间：2026-08-22

## 1. 最终目标

国内平台不是海外平台的资料副本，而是同一研究引擎下的国内来源适配层。研究者在两边都应能沿着同一条路径工作：

```text
研究问题 → 专题/事件 → 来源家族 → 文档 → 页级定位 → 证据门禁 → 国内外对读 → 可复现研究包
```

国内来源的目录、汇编、同期报刊、官方档案、民盟内部数据库和学术文章必须分层；只有研究流程、定位能力、证据状态和验收口径与海外平台对齐。

## 2. 当前基线

本基线由 `build_domestic_parity_matrix_20260813.py` 只读重算，声明 `body_read=false`：

| 指标 | 当前结果 | 解释 |
|---|---:|---|
| 国内专题 | 9 | 1941—1949 九个统一专题 |
| 导航可用专题 | 9/9 | 问题、来源、对位事件和研究包入口齐备 |
| 有严格页的专题 | 9/9 | 至少有人工核验页，不等于事件原件闭环 |
| 边界内可研究专题 | 9/9 | 可生成带边界的研究包 |
| `research_ready` 专题 | 0/9 | 每个专题仍有关键一手目标开放 |
| 国内事件关联页 | 639 | 专题事件索引行数，不是全部原始库页数 |
| 严格引用页 | 181 | 仅计人工门禁通过的页 |
| 四层证据链页级条目 | 197 | 主证据、交叉、负向和开放目标分层 |
| 四层证据链严格条目 | 179 | 可复核页级条目 |
| 学术元数据匹配 | 159 | 解释层，不替代一手材料 |

统一门禁为：

```text

failed_checks=[]
```

因此现在的平台已经是“可研究、但不越过证据边界”的国内研究工作台，不应宣传为国内史料全部收齐。

## 3. 三条工作线

### A. 一手资料主干

按最小闭环推进，不按下载量推进：

1. 1941 成立：成立宣言、成立会议、早期《光明報》及版本关系；
2. 1945 一大：政治报告、宣言、组织规程和同期刊物原版；
3. 1946 政协/拒参/李闻：正式声明、函电、抗议文件和同期原刊；
4. 1947 解散：10 月 27 日政府行政原件、11 月 6 日民盟总部公告；
5. 1948—1949：三中全会、新政协正式记录、代表名册和民盟代表表达。

每个目标固定经过：

```text
取得或确认路线 → staging manifest → SHA256/页数 → 页身份复核
→ dry-run → 正式库备份与写入 → integrity/外键/FTS → 研究包回链
```

### B. 学术解释层

纳入中央研究机构、权威期刊、正式出版社及高水平高校的可核验研究，用于解释概念、争议、研究史和档案线索。每条至少补齐作者、机构、刊物/学位、年份、稳定入口和全文状态。

学术层可以帮助发现 P0 原件，但不能把二次叙述升级成一手证据。

### C. 产品和质量层

国内与海外统一提供：

- 问题、年代、人物、组织、地点和来源类型检索；
- 专题时间线和事件关系；
- 文档—页—来源—SHA256 回链；
- 主张—证据—缺口研究包；
- 国内外同一事件对读；
- `catalogue_only`、`draft_ocr`、`strict_citation`、`research_ready` 明确徽章；
- 公开模式只展示允许公开的元数据和引用入口。

## 4. 未来 12 周的阶段目标

### 第 1—2 周：准入和 P0 原件接收

- 使用 `prepare_authorized_original_intake.py` 接收授权浏览器/档案馆取得的原件；
- 完成 1947 两个 P0 目标的实际搜索、显式映射和页身份审计；
- 1941 和 1946 目标同步补充可执行查档路线；
- 任何没有原件的目标继续保持 `OPEN`。

验收：每个已取得文件都有来源、记录号/档号、SHA256、页数、页身份和权利字段；没有文件时报告必须是 `WAITING_FOR_LOCAL_ORIGINAL`，而不是空正文。

### 第 3—5 周：三个旗舰专题

优先形成三个可交付专题：1941 成立、1946 政治选择、1947—1949 组织受压与转型。每个专题至少要有：

- 一组主证据；
- 一组独立同期交叉证据；
- 一组负向核查；
- 一张版本关系表；
- 一个可复现研究包；
- 一张国内外对读卡。

验收：只有同时满足上述条件和主证据关闭条件，才允许从 `partial` 升级为 `research_ready`。

### 第 6—8 周：检索与研究输出对齐

- 统一国内/海外专题卡片字段；
- 让每个研究问题三步内到达页级材料；
- 支持主张—来源—页码反向追溯；
- 将同期报刊、汇编重刊、官方档案和学术文章分层显示；
- 建立 10 个固定研究问题的回归集合。

验收：每个问题都能输出“依据、页码、版本、形成者、限制和未决问题”，不以模型摘要代替来源。

### 第 9—12 周：阶段收口和发布

- 完成国内外 parity 看板；
- 形成内部完整版与公开展示版的权限边界；
- 生成恢复包、manifest、来源覆盖报告和资源占用报告；
- 对重复文件建立版本关系，不自动删除本地资料；
- 对所有未闭合目标给出明确原因：未取得、权限锁定、目录-only、页链异常或待人工复核。

验收：至少三个旗舰专题 `research_ready`，其余专题有可执行的开放目标队列；完整门禁、SQLite 完整性、FTS、研究问题回归和公开边界全部通过。

## 5. 每轮固定验收

每一轮只接受以下证据：

1. 输入文件或官方路线的明确身份；
2. 来源、版本、SHA256 和页级 provenance；
3. 人工页身份复核，而不是 OCR 页数；
4. 正式库完整性、外键、FTS 和路径安全；
5. 研究包、搜索入口和公开模式同步更新；
6. 未闭合目标仍保持诚实状态。

禁止用以下指标替代完成度：候选条目增加、OCR 页数增加、查看器打开、门禁 `PASS` 或学术文章数量增加。

## 6. 当前下一步

当前最优先事项是等待或取得两个 1947 P0 原件，并用新的接收器进入 staging；在原件尚未到达前，继续做 1941、1946 的路线审计和现有页级证据整理，但不把替代本升级成原件闭环。

## 7. 双侧研究路径验收

除 parity 矩阵外，平台现在有一条可重复的国内—海外研究路径验收命令：

```bash
python3 scripts/domestic/build_domestic_foreign_parity_acceptance.py \
  --output work/domestic/domestic_foreign_parity_acceptance_current/REPORT.json
```

它会运行 36 个国内研究问题，并对每个专题同时检查国内问题路径、海外事件入口、学术交叉表、四层证据链、国内严格页和来源地图。它只查询既有搜索索引和元数据，不复制正文、不写正式 SQLite、不改变任何一手证据状态。

报告中的两个状态必须同时阅读：

- `status=PASS`：研究路径和对读基础设施可用；
- `research_content_status=OPEN_PRIMARY_GAPS`：事件定义原件仍未全部闭环。

因此，路径回归通过可以证明国内平台已经能像海外平台一样“进入问题、找到来源、回到页级证据”，但不能把它解释成国内一手史料已经收齐。
