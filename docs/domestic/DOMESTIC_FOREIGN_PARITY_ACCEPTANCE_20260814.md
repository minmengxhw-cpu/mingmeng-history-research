# 国内—海外统一研究平台：Parity 验收基线（2026-08-15 重算）

## 目的

“国内和海外一样发挥作用”不是让两边拥有相同数量的文件，而是让研究者在同一条路径上完成：

> 研究问题 → 事件 → 来源家族 → 文档 → 页级定位 → 引用门禁 → 多源对读 → 研究包

国内资料的目录、汇编、同期报刊、官方档案、扫描影像和学术文章仍必须分层；只有研究流程和可用能力与海外平台对齐，不能把不同来源压缩成一个资料数量。

## 与海外平台的能力对齐

| 能力 | 国内当前状态 | 收口标准 |
|---|---|---|
| 发现资料 | 来源地图、候选目录、调档清单 | 每条候选都标明来源家族、记录号、访问方式和下一步 |
| 阅读资料 | 核心可阅库、文档页、物理页入口 | 正文、OCR 草稿、目录和背景资料分层展示 |
| 页级引用 | `page_provenance`、SHA256、人工复核页 | 正式引用必须有页码、来源文件、哈希和复核说明 |
| 研究导航 | 九个专题、研究问题矩阵、事件墙 | 从问题页三步内到达页级材料 |
| 多源互证 | 国内—海外 crosswalk、四层证据链 | 区分独立原件、汇编重刊、同期报道和境外观察 |
| 学术解释 | 学术元数据和专题交叉表 | 作者、机构、刊物/学位、年份和稳定链接可核验 |
| 可复现输出 | JSON 研究包、引用卡、对读卡 | 另一台 Mac 可恢复并重新通过门禁 |
| 权限与公开边界 | public 模式、来源权利字段、staging 隔离 | 私有正文不进 GitHub；目录不能冒充正文；不绕过登录 |

## 旗舰专题收口顺序

### P0：1941 成立与早期组织

先补成立宣言原件影像、档号和版本关系。现有转录、汇编和同期材料继续作为导航与交叉证据，但不替代原始底本。

### P0：1946 拒绝参加国民大会与李闻事件

分别追踪正式声明/函电、《民主周刊》原版、抗议文件及司法/行政原件；把人物反应、同期报道和后续纪念拆成独立证据单元。

### P0：1947—1949 组织受压、恢复与新政协

优先取得 1947-10-27 政府文件、1947-11-06 解散/宣布非法原件，以及 1949 年新政协正式会议记录、代表名单、发言和民盟内部文件。

## 每轮工作循环

1. 从 `data/domestic/primary_retrieval_queue.json` 选择一个 P0 原件目标；
2. 取得或定位后写入 staging manifest，不直接写正式 SQLite；
3. 电子文本跳过 OCR，扫描影像只做定向 OCR；
4. 先完成来源 SHA256、页数、物理页/PDF 页和访问边界；
5. 人工视觉复核后才允许进入严格引用候选；
6. 重算 parity 矩阵和统一门禁；
7. 只有主证据、交叉证据、负向核查、版本关系和研究包同时闭环，专题才可从 `partial` 变为 `research_ready`。

## 明确禁止的替代指标

- 候选数增加，不等于研究完成；
- OCR 页数增加，不等于正式可引用；
- 汇编重刊，不等于独立原件；
- 官方查看器可打开，不等于已经取得本地原件；
- 学术文章质量高，不等于可以替代一手材料；
- 统一门禁 `PASS`，不等于 `research_content_status` 已关闭。

## 项目最终完成定义

至少三个旗舰专题达到 `research_ready`，其余专题有清楚的开放原件队列；研究者能够从一个国内或海外研究问题进入同一事件框架，追到来源、页码、版本和复核记录，并导出不含私有正文的可复现研究包。
