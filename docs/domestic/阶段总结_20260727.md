# 国内盟史资料平台阶段总结（截至 2026-07-27）

## 本阶段完成

国内盟史资料工作已从“候选线索与零散 OCR”推进到“有来源校验、有质量分层、有回滚能力的本地检索库”：

- 国内候选记录保持 689 条，必填字段和本地路径校验全部通过，accepted 660 条。
- CC/MiniMax 前期混批 OCR manifest 已拆分、规范化；新增下载口径纠正为 0，避免把既有本地文件误报为新下载。
- 第 113/114 卷《大公报》共 480 页 OCR 完成并通过 SHA、页数、chunk 连续性核验。
- 本轮正式导入 58 个来源文档、75 个 OCR 检索单元，覆盖 3598 个物理页。
- 本地数据库达到 986 documents、1503 pages、1503 FTS rows；完整性正常，FTS 与 pages 完全对齐。
- 国内资料继续以 `source_platform=domestic` 与海外 FRUS、CIA、Wilson、Hoover、DRNH 等来源并列，研究平台已不再只是海外资料入口。

## 当前资料结构

1. 1941：成立前后文件、《新华日报》《光明报》等同期材料。
2. 1944—1945：民盟改组、临时全国代表大会、政治报告与《民宪》材料；目前仍以汇编/转载互证为主，原始单行本和完整原期是下一硬缺口。
3. 1946：政协、国民大会争议、民盟政治主张及香港《光明报》连续期号。
4. 1947：民盟危机、被迫解散前后公报与报刊材料，以及《大公报》《大刚报》《观察》等同期报道。
5. 1948—1949：三中全会、新政协和多党合作转型线索，覆盖仍弱于 1946—1947。

## 质量边界

- OCR 只作为检索草稿，全部保持 `citation_ready=false` 或等价的 pilot/needs-human-review 标签。
- 来源 SHA、物理页数和本地路径已核对，不等于题名、作者、日期、文章边界和逐字文本全部校订。
- P3-023 暂不入库，因为自动 issue/article 边界不可靠。
- 两份试用数据库影像的旋转 OCR 虽有改善，但 CC manifest 的路径仍指向旧低置信度 OCR；暂不入库，等待重建旋转版 provenance 或补高清原件。
- 数据库原有 15 条历史分类外键残留与本批次无关，单列为后续维护任务。

## 下一阶段建议

1. 对 75 个 OCR 检索单元做事件导向抽检，优先 1941 成立、1945 一大、1946 政协、1947 危机、1948—1949 转型。
2. 为高价值文章建立页级/文章级边界与短摘录，逐条提升 citation readiness，而不是整本升级。
3. 逐期核校 P3-023《观察》合订本，形成可靠 issue manifest 后再入库。
4. 补强 1944—1945 原始单行本、1948—1949 同期报刊与正式文件，降低对后出汇编的依赖。
5. 单独修复历史 `document_classifications` 的 15 条孤儿关系，并在修复前后做数据库备份和回归。
6. 平台检索继续采用 FTS + LIKE 混合策略，解决“民盟、张澜、上海”等二字词在 trigram 下的零命中问题。

## GitHub 与本地数据边界

GitHub 保存代码、结构化 metadata、验收报告和阶段总结；163 MB SQLite、扫描原件、OCR 全文和数据库备份继续本地保存。数据库迁移到其他电脑时应单独复制 `data/research_index.sqlite` 并核对 SHA256。
