# 李公朴、闻一多专题原刊访问路线审计

审计日期：2026-08-15  
专题：`domestic-1946-li-wen`  
审计范围：只记录公开目录、官方盟史说明和原刊调取线索；不复制商业影印正文，不把后出叙述当作原件。

## 结论

当前专题有三类可复核材料：

- 1983 年公开文献汇编中 3 个民盟声明页，已经完成页级人工复核，可作为“汇编重刊”严格引用；
- 1947 年《光明報》新二十二号首版，已经完成刊期和纪念专页定位，可作为同期报刊的严格页级入口；
- 《民主周刊》出版范围和相关期号目录线索，可以指导下一次原刊调取。

但《民主周刊》1946 年 7 月相关原版、民盟抗议文件独立底本、司法/行政档案仍未取得逐页影像。因此：

## 已确认的路线

### 民盟云南官方盟史：刊物范围与机构背景

- 页面：[抗日战争末期的昆明《民主周刊》](https://www.minmengsh.gov.cn/detailpage/lshm-5881f0f7-d19e-11ec-8d57-8c554a2845d4.html)
- 页面说明：刊物由民盟云南省支部出版，1944-12-09 至 1946-08-02 共 3 卷 71 期；李闻事件后被迫停刊。
- 平台归类：`official_retrospective` / `navigation_only`
- 能做什么：确认刊物的出版机构、时间范围、作者群体和原刊追索边界。
- 不能做什么：不能证明某一期原刊影像已经取得，也不能替代正文页级引用。

### 商业影印目录：缩小到具体期号和篇目

- 页面：[《光明报》1946 年期号目录](https://jiuwenku.com/detail/9f5995ef081bd721/)
- 页面列出的可追索线索包括：1946 年第 3 期的“李闻案民盟再致政府函”、第 5 期的“李闻案特辑”、第 6—8 期的“李闻惨案前后的昆明”及相关社论/目录。
- 平台归类：`commercial_surrogate_catalogue` / `navigation_only`
- 页面显示为付费 PDF 影印目录；当前没有把商业正文下载到本地，也没有把目录题名当作原刊页证据。
- 能做什么：为 NLC、云南省图书馆、民盟云南地方档案或其他缩微馆藏提供期号检索词。
- 不能做什么：目录本身不能证明文章的完整页界、署名、版次或正文版本。

### 现有本地严格入口

- 1983 汇编民盟声明：页 `18936`、`18945`、`18948`，证据性质是 `public_sourcebook_scan / L2`。
- 《光明報》新二十二号（1947-08-01）页 `1768`，证据性质是 `contemporary_newspaper_scan / L1`。
- 这些页的 provenance、来源 SHA256 和人工复核记录已经在正式库中；它们不替代《民主周刊》1946 年原版。

## 下一次最小调取闭环

1. 先向可提供原刊影像的馆藏核对 1946 年第 3 卷第 16 期和第 19 期；这两个期号是公开研究线索，必须以馆藏目录或原刊报头重新确认。
2. 重点检查 1946 年 7 月李公朴遇害、7 月 15 日闻一多遇害及其后民盟抗议/追悼相关页，不能只下载目录页。
3. 获取允许保存的影像后，保存期号、日期、馆藏标识、PDF/影像页号、复制许可和整期 SHA256。
4. 对报头、日期、期号、页界做人工视觉复核；OCR 只生成 `draft` 检索文本，不能自动变成 `citation_ready`。
5. 将原刊与 1983 汇编声明、1947《光明報》纪念页和后期转录分别建链，标出同文、改写、转载、缺页和无法确认的差异。

## 证据边界

- 官方盟史文章是后期机构说明，不能替代 1946 年原刊。
- 商业目录是导航和购买线索，版权与正文再利用状态未知。
- 1947 年纪念报刊页只能证明同期纪念传播，不能倒推 1946 年案件的全部事实或责任。
- 汇编页可以做页级重刊引用，但不能自动升级为独立抗议文件或司法档案。
- 未取得影像前，不新增正式页号、不写入正文、不提升主证据状态。

## 验收标准

本专题只有在获得至少一组 1946 年原刊/独立抗议文件影像，并完成逐页 provenance、视觉复核、OCR 草稿与版本对读后，才可推进 `primary_evidence_closed` 评估。届时仍需保留司法/行政档案是否取得的单独缺口，不把一个来源链扩展成整个案件的全部证明。
