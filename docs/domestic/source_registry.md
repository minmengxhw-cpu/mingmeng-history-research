## 使用规则

- 来源卡是机构和入口登记，不等于已有记录级原件。
- source_registry.json 的 verified_entry 只表示入口或页面可追踪；具体档号、页码、影像和复制权利仍须逐条复核。
- 公开前台展示候选时同时显示原始性等级、证据说明、不确定性和访问/权利状态。
- L4、LX 只作线索，不进入核心证据闭环。
- 外部 CLI 只接收公开检索问题，不读取本地数据库、扫描件、OCR 或私有项目文件。
