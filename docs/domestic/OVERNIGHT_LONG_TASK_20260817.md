## 目标

Codex 已把海外平台做成“问题 → 检索 → 专题 → 页 → 引用门禁”。国内侧入口和研究路径已经能走通，但研究者打开首页仍像在翻资料库，不像在用研究平台；九个专题的事件定义原件也全部开放。

本长任务不是堆下载量。通宵目标是：

1. 国内平台有一个明确的工作台入口，和海外同一套研究路径；
2. 已有本地高价值公开扫描完成页级身份/负向核查收口，并接回专题；
3. P0 原件（1941《光明報》、1947 公函/解散公告）只做可执行路线审计和公开镜像探查，不把替代材料写成闭环；
4. 每轮结束都留下可重算门禁和 STATE，下一批能接着干。

## 禁止

- 不把汇编、会刊封面、后期转录、OCR 草稿标成 `primary_evidence_closed` 或 `research_ready`
- 不整本 OCR 已有电子正文或已对账页链
- 不删除原件、备份、OCR 草稿
- 不自动提升 `citation_ready`，除非完成页级视觉复核并写下复核范围
- 不写 GitHub 历史、不提交正文原件
