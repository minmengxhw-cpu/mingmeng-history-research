# 1941 年成立原刊访问路线审计

审计日期：2026-08-15  
专题：`domestic-1941-formation`  
审计范围：只核对公开馆藏元数据和访问入口，不下载、复制或外发正文原件。

## 结论

1941 年成立专题目前可以稳定使用三层材料：

1. 1946 年《民主同盟文獻》汇编中的 5 个页级严格引用页，用于复现汇编重刊文本的页码和出处；
2. 岭南大学《光明報，1941》剪报索引，用于定位 1941 年 10—11 月原刊的日期、页码和版位；
3. 香港大学 Special Collections 的《光明報》1941 年缩微胶卷馆藏入口，用于申请调取原刊。

但目前仍没有取得 1941-10-10《光明報》原刊影像、原刊页码/版次，或能够证明成立宣言底本关系的独立原始印本。因此本专题仍保持：

```text
primary_evidence_closed = false
research_ready = false
```

不能把汇编重刊、后期公开转录或馆藏目录当作 1941 年原刊本身。

## 已核实的公开路线

### 岭南大学：剪报索引

- 页面：[\[光明報，1941\]](https://commons.ln.edu.hk/profmkchan_indexlist/14/)
- 机构：Lingnan University Digital Commons；陈明銶教授研究藏书
- 页面说明：索引以《光明報》为单位，手写记录 1941 年 10—11 月剪报的新闻标题、出版日期、印行页码，并附部分版位说明；页面标明共有 13 项条目。
- 平台归类：`university_finding_aid` / `navigation_only`
- 能做什么：把原刊追索从“泛指一份报纸”缩小到具体日期、印刷页码和版位。
- 不能做什么：不能证明 1941-10-10 成立宣言的原刊影像已取得，也不能代替正文引用。

### 香港大学：1940 年代报纸馆藏表

- 官方馆藏表：[Hong Kong Newspapers - Chronological List 1940s](https://lib.hku.hk/sites/all/files/files/hkspc/pathfinders/newspaper_1940s_update_072021.pdf)
- 记录：`光明報`，格式为 Microform，访问方式为 Special Collections 内的 Microfilm，馆藏范围为 1941-09-18 至 1941-12-12，目录标注无缺期。
- 平台归类：`university_catalogue_access_route` / `access_route`
- 能做什么：确认 1941-10-10 落在馆藏范围内，并提供正式馆藏调取路线。
- 不能做什么：馆藏表本身不是逐期扫描，不能证明已经取得某期影像、版次、页码或复制许可。

### 香港大学：馆藏目录入口

- 目录入口：<https://julac.hosted.exlibrisgroup.com/primo-explore/fulldisplay?docid=HKU_IZ21440249790003414&vid=HKU&lang=en_US>
- 现有本地来源地图：[`1941_formation_source_map.json`](../../data/domestic/1941_formation_source_map.json)
- 当前本地记录已保存馆藏入口及其 SHA256；没有把外部目录正文写入正式库，也没有把访问路线升级为 `citation_ready`。

## 下一次调取的最小闭环

只有完成下列步骤，才可以考虑把原刊加入正式研究包：

1. 按馆藏目录向 HKU Special Collections 申请或现场调取 `1941-10-10`《光明報》整期，必要时同时调取 `1941-10-09`、`1941-10-11` 作为版面边界对照。
2. 保存馆藏标识、期号、日期、卷期、印刷页码、影像页号、调取方式和复制许可状态；先生成来源 manifest，再处理正文。
3. 对封面/报头、日期、期号和目标页做人工视觉核验，建立每一页的图像 SHA256；不能只凭 OCR 文字判断。
4. 以 PaddleOCR 或其他本地 OCR 生成 `draft`，保留模型版本、渲染参数、页图 SHA、OCR SHA 和低置信度页清单；OCR 不自动获得一手证据等级。
5. 将原刊与 1946 汇编重刊、1941 年后期转录做版本对读；分别标记增删、标题差异、页码差异和无法确认之处。
6. 只有在页界、来源、影像和人工复核均可重放时，才把对应页标记为 `citation_ready`；事件是否达到 `primary_evidence_closed` 仍需确认底本关系和独立来源链。

## 禁止的捷径

- 不把 HKU 目录的“无缺期”解释成已经取得扫描页。
- 不把岭南大学剪报索引的页码解释成成立宣言正文。
- 不把 1946 汇编重刊页的 `strict_citation` 解释成 1941 原刊。
- 不因为后期公开转录可全文检索，就把它提升为同期原件。
- 不向 GitHub 提交正文原件、OCR 正文或本地绝对路径；公开仓库只保留来源地图、manifest、规则和审计结论。

## 验收标准

本审计记录完成的是“路线可执行”而不是“原件已取得”。验收必须同时看到：

- 1941-10-10 原刊实际影像或正式复制件；
- 影像与馆藏标识、日期、页码、SHA256 的逐页绑定；
- 人工视觉复核记录；
- OCR 仅作为可检索草稿，并与原图分层；
- 1946 汇编、原刊和后期转录三者的版本关系说明；
- 统一平台门禁继续通过，且没有把原刊缺口误报为已闭合。
