# 民盟全媒体数据库浏览器接入审计（2026-08-14）

## 审计目的

记录当前环境对已授权民盟全媒体数据库入口的实际可达性，防止把“用户曾经登录过”“目录锚点已登记”或“查看器页面可见”误写成已取得正文原件。

目标入口：

- HTTP：`http://www.minmeng1941.cn/WEB/INDEX.html`
- HTTPS：`https://www.minmeng1941.cn/WEB/INDEX.html`

## 当前实测结果

| 检查项 | 结果 | 解释 |
|---|---|---|
| 默认受控浏览器打开 HTTP | `ERR_BLOCKED_BY_CLIENT` | 客户端在导航层拦截，未读取页面正文、目录详情或下载接口 |
| 默认受控浏览器打开 HTTPS | `ERR_TIMED_OUT` | 页面最终显示“无法访问此网站”，未读取正文或登录状态 |
| 用户此前使用的 Chrome 会话 | 当前环境没有可用的 Chrome 浏览器扩展连接 | 不能假定 Codex 能继承用户 Chrome 的登录会话 |
| 本轮下载/保存 | 未执行 | 没有文件、正文、Cookie、Local Storage 或会话凭据被读取 |

因此，本轮不能确认 1941-10-10《光明报》头版“启事”、1941-10-16 社论、1946 拒参文种或 1947 公告在该平台中的详情页是否可下载，也不能更新任何原件的 SHA256、页数或权限状态。

## 当前证据不变量

以下状态保持不变：

```text
body_read=false
formal_db_written=false
auto_download=false
auto_promote_primary_closed=false
```

民盟全媒体数据库在 `data/domestic/source_registry.json` 中仍是 `catalogue_verified_authorized_pending`；已有目录候选继续保留，但不升级为正文或严格引用页。

## 恢复接入后的最小交接包

用户在已登录且允许保存的浏览器中完成一次详情页下载后，只需把以下元数据交给本项目的 staging 流程：

1. 详情页 URL、记录号或平台内部文献 ID；
2. 题名、机构/作者、文献日期和文种；
3. 下载文件的原始文件名、字节数、SHA256 和页数；
4. PDF 页与印刷页/物理页的对应关系；
5. 访问、复制和公开展示边界；
6. 需要人工复核的页范围。

电子文本直接进入检索层；只有图像型页面且确实能缩小专题 `open_targets` 时才进入定向 OCR。任何文件先进入 staging，完成来源哈希、页级 provenance 和人工视觉复核后，才允许申请严格引用门禁。

## 后续目标

恢复浏览器会话后，优先按以下顺序检查：

1. 1941-10-10《光明报》“启事”及成立宣言/对时局主张纲领；
2. 1941-10-16《中国民主同盟的成立》社论；
3. 1946-11-14《紧急通告》及同期拒参声明/函电；
4. 1947-11-06 民盟总部解散公告和 11-07 张澜呼吁书。

本审计记录的是访问能力边界，不是资料缺失结论；在授权详情页实际可保存之前，以上目标继续保持开放。
