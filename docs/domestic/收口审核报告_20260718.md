## 五、交给 MiniMax / Grok 的接手边界

- 终端模型只负责公开网页线索、目录线索和候选摘要；不得读取本地数据库、扫描件、私有路径或凭二手材料直接接受 L1。
- 新增材料必须先去重，再填写来源、题名、日期、形成者、页码/图像定位、证据类型、权利状态和不确定性说明。
- 只有在原刊或官方数字影像能够给出可复核定位时，才允许由 Codex 审核升级接受级别。
- 每轮修改后必须运行：

```bash
python3 scripts/domestic/validate_candidates.py data/domestic/candidates.jsonl
python3 scripts/domestic/validate_event_coverage.py data/domestic/candidates.jsonl data/domestic/event_coverage.json
python3 scripts/domestic/ingest_domestic.py --db data/research_index.sqlite --sources data/domestic/source_registry.json --candidates data/domestic/candidates.jsonl

```
