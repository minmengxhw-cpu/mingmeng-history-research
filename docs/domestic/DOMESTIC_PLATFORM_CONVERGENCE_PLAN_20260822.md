# 国内研究平台与海外平台能力对齐规划

更新时间：2026-08-22  
适用仓库：`mingmeng-history-research` 及其国内资料工作流

## 一、项目终点

国内平台的目标不是继续堆积文件，而是让研究者对国内资料也能完成与海外资料相同的闭环：

> 找到资料 → 判断来源等级 → 定位到页/段 → 形成可复核引用 → 放入事件、人物、组织和时间线 → 输出研究包。

国内与海外使用同一套证据状态、来源链、检索和验收规则；差异只体现在资料获取渠道和版权/访问条件，不体现在研究质量标准上。

## 二、当前基线与真正瓶颈

当前国内平台已经具备导航、限定检索、来源页、事件页、质量页、学术资料层和研究包等产品骨架。最新统一门禁基线为：9/9 主题可导航、9/9 主题可做边界内研究，国内事件关联 639 条、页级关联 624 条；正式库共有 285 个严格页级状态，九专题来源地图中有 245 个页级条目（137 strict、10 review-only、95 navigation-only），9/9 主题仍未达到 `research_ready`。候选资料 690 条，学术元数据 288 条，其中文章 99 篇。

本轮又完成了 1946 年旧政协相关汇编 17 页的页身份视觉复核和严格页级状态接入；这增加了可定位、可复核的页级能力，但没有把汇编重刊误报为政协原始记录，也没有关闭专题的一手证据缺口。

因此当前瓶颈不是页面数量，也不是再做一轮 OCR，而是：

1. 关键事件能否取得可核验的原始影像或可信的官方页级复制件。
2. 每条重要判断能否回到载体、日期、版次/页码、档号或稳定链接。
3. 电子文本、扫描件、OCR、汇编重印本、目录和学术研究能否明确分层，不互相冒充。
4. 库中体量能否在不损失证据的前提下控制：重复件不重复入库，电子版不重复 OCR，低价值材料不进入正式检索层。

## 三、统一的资料分层

### A 层：原始/当时材料

成立宣言、会议记录、当时报刊、官方公报、档案馆原件影像、当事组织的同期文件。只有这一层可以直接关闭“主证据缺口”；必须保留载体、日期、页码/版次、档号、文件哈希和获取条件。

### B 层：正式复制或官方汇编

官方影印、正式汇编、机构公开扫描、经馆藏页面确认的复制件。可以形成严格的页级引用，但要明确它是复制/汇编，不自动等同于独立原件。

### C 层：学术研究

优先纳入中央研究机构、重点高校教师或研究团队、正式学术期刊/出版社的文章和专著。登记作者、机构、刊物、年份、DOI/ISBN、页码和引用的材料类型。C 层用于解释、争议梳理和线索发现，不能替代 A/B 层的原始证据。

### D 层：目录、索引、导航和线索

馆藏目录、查档指南、书目索引、网页介绍、二手转载。D 层可以指导调取，但不能被标成 `citation_ready`，也不能关闭主证据缺口。

## 四、分阶段路线

### 阶段 0：收口、减负和可追踪化（1—2 天）

- 以 `primary_gap_closure_matrix.json` 的 9 个主题为唯一主线，清理“看起来很多但不能引用”的计数。
- 给每个候选件生成或补齐：来源角色、来源等级、载体、日期、页码/档号、SHA256、获取状态、复制许可和证据状态。
- 电子文本跳过 OCR；已有完整页链的扫描件只做缺页/版次检查；目录和索引只进入导航层。
- 保留原始资料，不做不可恢复删除；通过去重、分层索引、派生文件清单和可恢复归档降低正式库负担。
- 验收：来源地图与 SQLite 的 `citation_ready` 状态完全一致；统一门禁 `PASS`；0 个目录/路线页冒充严格引用。

### 阶段 1：先闭合两个 P0 事件（2—4 周）

- `1941 年中国民主政团同盟成立`：优先执行 HKU《光明報》1941 微缩胶卷调取路线，首个目标日为 1941-10-10；取得影像后记录 call number、载体、影像 SHA256、页码和复制许可，再决定定向 OCR。
- `1947 年民盟被迫解散/非法解散`：将同期报刊、官方公报、组织文件和已存页级证据分成“直接事实”“当时报导”“后出回忆/汇编”，逐条补齐页级链条。
- 每个事件形成一个研究包：事实时间线、主证据、辅助证据、争议点、未闭合项、可直接引用的页码清单。
- 验收：P0 事件达到 `research_ready` 的定义，或明确记录阻塞原因、已完成的调取动作和下一次可执行入口；不能用“已有汇编”掩盖原件缺口。

### 阶段 2：批量闭合 P1 事件并建立学术解释层（4—8 周）

依次处理 1945 年第一次全国代表大会、1946 年李/闻事件、1946 年政治协商会议、1946 年拒绝参加国民大会。每个主题按“原始材料优先、官方汇编补充、学术研究解释、目录只导航”的顺序推进。

学术层采用严格元数据门槛：作者与机构可核验、刊物/出版社可核验、文章有页码或稳定全文入口、材料结论与原始证据分开记录。重点高校或中央研究机构的身份是优先级，不是自动可信标签。

### 阶段 3：补齐 P2 并做国内/海外统一研究产品（8—12 周）

处理 1944 年改组、1948 年第三次中央全会/“五一口号”、1949 年新政协。随后把国内和海外资料接入同一研究工作台：

- 统一事件、人物、组织、地点、时间和来源实体。
- 支持按来源等级、证据状态、时期、机构、语言和资料类型过滤。
- 支持“事件卡”“人物卡”“组织关系图”“证据时间线”“国内/海外对照包”。
- 一键导出带页码、档号、哈希和状态标记的 Markdown/CSV/引用包。
- 搜索结果必须显示“可引用”“仅导航”“学术解释”“待复核”，不把相关性分数当作证据等级。

## 五、每份资料的流水线

```text
候选发现
  → SHA256/文件级去重
  → 来源角色与资料等级判断
  → 载体/日期/档号/页码元数据
  → 电子文本提取或定向 OCR
  → 页级 provenance
  → 事实/引用/学术解释分离
  → SQLite/FTS 入库
  → 统一门禁与抽样复核
  → 研究包和前端展示
```

任何一步不完整都保留为 `partial`、`navigation_only` 或 `review_only`，不得自动升级成严格引用。OCR 只是检索和定位手段，不能替代影像核验。

## 六、平台要达到的验收指标

1. 9/9 国内主题有可工作的导航、限定检索和研究包入口。
2. P0 主题首先闭合，随后 P1、P2 按证据优先级推进；每个主题都有明确的开放缺口清单。
3. 100% 的 `citation_ready` 页面可追溯到文件/链接、页码或版次、SHA256/档号和来源状态。
4. 来源地图、正式 SQLite、研究包和前端状态一致，统一门禁无失败项。
5. 正式检索层不重复收录同一文件，不对已有电子文本做无意义 OCR；原始资料仍可追溯、可恢复。
6. 学术文章能被检索和引用，但任何学术结论都显示其证据层级，不冒充同期原始材料。
7. 研究者拿到一个事件后，能在一次工作流内完成“发现—判断—引用—输出”，而不需要重新翻找原始目录。

## 七、推进循环

每一轮只做一个可验收闭环：

1. 从开放缺口队列选一个最高优先级目标。
2. 先查已有正式库和重复关系，决定“跳过、定向 OCR、申请原件或补元数据”。
3. 只把新增且可验证的证据写入正式层；其余留在候选/导航层。
4. 跑 JSON、SQLite 完整性、来源一致性、研究包和前端回归门禁。
5. 更新状态文件，明确下一动作、阻塞原因和证据计数。
6. 再进入下一个目标，不用“文件数增长”代替完成度。

本规划的收口条件是：国内资料可以像海外资料一样支持带出处的研究判断；不是把所有国内文件都 OCR 完，也不是把所有目录都标成已完成。
