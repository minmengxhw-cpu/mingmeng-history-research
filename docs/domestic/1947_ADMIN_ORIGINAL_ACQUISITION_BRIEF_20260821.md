# 1947 年民盟非法化与解散：行政原件最小调档包

更新时间：2026-08-21
当前状态：`OPEN_PRIMARY_GAP`

## 目标

只追两类事件定义原件：

1. 1947-10-27 政府宣布民盟为非法团体的公函、命令或同一行政链中的原始文书；
2. 1947-11-06 民盟总部解散公告/正式声明及其可核对的原始底本。

同期报刊、后出汇编和档案目录可以建立时间线与追索关系，但不能替代上述两类原件。

## 取得后的统一接收字段

每一件文件进入 staging 前必须具备：

- 机构、全宗/案卷号、文号或记录号、题名、形成日期和日期角色；
- 原始文件或页图的 SHA256、字节数、页数、PDF 页/物理页/印刷页关系；
- 下载/阅览入口、访问时间、保存许可、复制许可和公开展示边界；
- 页身份复核记录、相邻页边界、正文是否逐字校读、OCR 是否仅为衍生层；
- 与 1947-10-27、1947-11-02、1947-11-05、1947-11-06、1947-11-11 各节点的版本关系。

电子文本优先直接进入检索层；扫描件只对确定有价值的页做定向 OCR。任何材料先进入 staging，不直接写正式 SQLite，也不因为 OCR 完成而关闭主证据缺口。

## 关闭条件

只有同时满足以下条件，1947 主证据状态才可从 `OPEN_PRIMARY_GAPS` 申请变更：

1. 至少取得并核验一件政府/行政原始文书，以及一件民盟总部公告或正式声明原始底本；
2. 每件都有可复现的机构、档号/记录号、日期、版本和页级 provenance；
3. 能把 10-27 行政决定、11-02/11-05 执行链和 11-06 组织声明的关系写成有证据依据的时间轴；
4. 人工页身份和边界复核通过，正文与 OCR 状态分开登记；
5. 公开研究包只暴露允许公开的元数据和引用入口，不泄露私有正文或本地路径。

在此之前，平台可以继续提供高质量的同期报道对读和学术解释，但必须保留“行政原件未闭合”的醒目标记。
