## 固定入场门禁

对任一 P0/P1 条目，必须先在本地 staging 登记：

1. 详情页 URL、记录号、题名、日期和文种；
2. 原始文件名、字节数、SHA256、页数和访问/复制边界；
3. PDF 页、印刷页/物理页映射及版本关系；
4. 电子文本或图像型文件的 OCR 分流决定；
5. 人工视觉复核范围和 `human_verified` 决定。

没有以上信息时，条目只能进入追索队列，不能写入正式正文层、不能生成严格引用卡，也不能关闭专题 `open_targets`。不因目录数量增加而改变研究完成度。
