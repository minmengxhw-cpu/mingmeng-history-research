# 国内—海外民盟研究平台对齐计划（基线更新：2026-08-30）

## 一、最终目标

国内平台要达到海外平台同等的研究闭环：

```text
提出问题 → 进入专题 → 检索来源 → 阅读原件/页 → 查看页级引用
→ 区分一手与解释层 → 形成研究包 → 保留可复核证据链
```

“资料已经登记”不等于“可以引用”。国内平台必须同时呈现发现层、研究可用层和正式引用层，不能用候选数量替代证据质量。

## 三、五条工作线

### 1. P0 一手原件线

优先关闭两组原件：

- 1941 年民盟成立宣言、成立相关原刊或档案影像；
- 1947 年政府公函、民盟解散/宣布非法公告及其页级版本链。

固定流程：

```text
授权原件进入 incoming → SHA256 → 文件/页面 manifest →
电子文本直接解析 → 仅图片页 OCR → 页级人工核对 → citation-ready
```

不得对已有电子版重复 OCR；不得把锁定查看器、后期汇编、报刊报道自动升级为事件定义原件。

### 2. 时间轴与地方史线

在不再把民盟史压缩成“被迫解散史”的前提下，按时间推进：

- 1941：成立、机关报、组织来源；
- 1944：改组、更名、纲领变化；
- 1945：第一次全国代表大会、延安会谈、抗战结束后的组织转型；
- 1946：旧政协、李闻事件、拒绝国民大会；
- 1947：二中全会、地方活动、政治压制、解散；
- 1948—1949：香港活动、五一口号、新政协和建国前后组织转型；
- 1949 年以后：上海地方组织、人物、基地和参政议政史。

每个时期至少保留一个原始来源家族、一个同期交叉来源和一个学术解释入口。

### 3. 学术解释线

学术资料只承担解释、争议定位和概念对照，不替代一手史料。优先级为：

1. 985 高校、中央研究机构或正式学术期刊的稳定全文；
2. 作者、机构、刊物、年份、页码和稳定 URL 齐全的研究；
3. 只有元数据或摘要的记录，停留在发现层；
4. 新闻、转载和一般网页，只作为线索，不进入学术主证据。

学术条目必须标明 `fulltext_status`、版本关系、来源入口和是否允许页级引用。

### 4. 产品与检索线

国内与海外保持同一套用户动作：

- `/research/questions`：从问题进入；
- `/research/<topic>`：国内外对读；
- `/domestic/library`：核心可阅文档；
- `/domestic/search`：国内限定检索；
- `/cite/<page_id>`：页级引用门禁；
- `/research/<topic>/packet`：导出研究包。

候选详情页必须显示档号、来源、访问状态、权利、不确定性和下一步，不把目录卡伪装成正文页。

### 5. 质量、资源与发布线

- GitHub 只保存代码、结构化元数据、manifest、报告和测试；原件/OCR/数据库留在本地数据层；
- 每次入库先做去重和 OCR 判定，电子版不重复 OCR；
- 原件、派生文本、索引和备份分层保存；
- 所有批次可通过 manifest、SHA256 和回滚副本恢复；
- 公开模式只显示明确允许公开且已过最低证据门禁的记录；
- 任何“PASS”都必须同时报告内容状态，不能把机制通过写成研究完成。

## 四、阶段验收门槛

### M1：P0 原件闭环

- 1941、1947 目标均有本地原件或明确的授权获取状态；
- 每页有文件、SHA256、页码和 provenance；
- 电子版/OCR 路由无重复；
- 关键结论可从专题页跳到页级引用。

### M2：国内时间轴完整可用

- 9 个既有专题全部保留；
- 1941—1949 各阶段都有一手候选和交叉材料；
- 不再由 1947 解散事件独占国内首页叙事；
- 每个专题都有开放缺口和下一步调档动作。

### M3：学术解释层可用

- 288 条元数据完成字段完整性检查；
- 23 条全文队列完成版本、权限和稳定入口复核；当前 17 条 S/A 优先队列已有有效正式来源行或同 SHA 页级复用入口，但不等于 `citation_ready`；
- 学术资料与一手资料在页面、研究包和引用中明确分层；
- 没有正文读取证据的条目不得生成正式引文。

### M4：研究问题回归

建立覆盖成立、改组、一大、政协、李闻事件、拒参国民大会、解散、五一口号和新政协的固定问题集，逐题检查：

```text
是否找到来源 → 是否能读到原件页 → 是否能定位页码
→ 是否标明证据等级 → 是否保留反向/不确定证据
```

### M5：发布与恢复

- 本地服务、公开模式和 GitHub 代码分别验收；
- 数据库 manifest、原件哈希、索引和备份可恢复；
- 资源增长有预算和清单；
- 删除任何资料前必须有单独授权和可恢复副本。
