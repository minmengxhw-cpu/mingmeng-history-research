## 目标

国内平台的目标不是把资料堆得更多，而是让研究者可以像使用海外资料平台一样，完成：

1. 找到资料；
2. 判断资料是什么、来自哪里、能否作为一手证据；
3. 定位到文档和页码；
4. 在不复制正文原件的情况下复现检索和引用路径；
5. 把多个来源组织成时间线、人物/组织关系和可审计的研究结论。

国内资料与海外资料使用同一套证据链和验收规则，但保留中文报刊、档案影印件、民盟内部数据库、汇编、学术研究等不同来源类型的差异。

## 资料分层

所有资料必须同时保存来源类型、来源路径、文件 SHA256、文档/页码定位和当前复核状态。

| 层级 | 含义 | 可做什么 | 不能做什么 |
| --- | --- | --- | --- |
| L0 | 目录、书目、查档线索、访问路线 | 发现资料、建立待办 | 不能当作正文证据 |
| L1 | 可公开访问的导航页、目录页、扫描页定位 | 复现入口、定位原件 | 不能冒充已核验正文 |
| L2 | 汇编、重印本、回忆录、后出整理 | 建立事件线索、交叉核对 | 不能自动等同于独立原始记录 |
| L3 | 同时代独立报刊、档案影印件、会议原始记录、正式公文 | 作为一手证据候选 | OCR 草稿仍需人工页级复核 |
| L4 | L3 已完成页级人工复核，来源链和引用路径可重放 | 进入 `citation_ready` / `research_ready` | 不能脱离出处单独生成结论 |

学术论文单独标记为 `scholarship_context`：优先收录 985 高校、中央研究机构、权威学术期刊和正式出版社的研究，用于概念、争议和研究史背景；它们可以解释一手资料，但不能替代 L3/L4 原件。

## 五条建设主线

### 1. 资料发现与收口

按 1941—1949 时间轴和九个专题建立 P0/P1 队列。每个 P0 目标都要回答“缺的究竟是原件、完整版本、独立来源，还是页级定位”。

优先顺序：

1. 1941 民盟成立的独立形成文件、会议记录和版本关系；
2. 1944 改组/名称变化的会议记录和 contemporaneous record；
3. 1945 年大会完整原始记录、报告和代表发言；
4. 1946 年旧政协、拒绝国大、李闻事件的独立记录和报刊链；
5. 1947 年政府公文、报刊和民盟回应的相互印证；
6. 1948 年第三次中央全会、五一口号及香港线索；
7. 1949 年新政协、发言、代表名单和会后组织变化；
8. 学术研究史、争议综述和专题论文作为第二层解释材料。

每次只收一组可以闭环的资料，不以“下载数量”作为完成标准。

### 2. OCR、转录与正式入库

- 有电子文本的文件直接抽取、规范化和校验，不重复 OCR；
- 只有扫描图像的文件才进入 OCR 队列；
- 本地 PaddleOCR 只产生 `draft`，必须保留原图、渲染参数、模型版本、OCR 文件 SHA256 和页级置信度；
- 页图身份、标题、页码、来源和 OCR 文本分开验收；
- 低置信度、版式复杂、竖排或缺页材料进入人工复核队列；
- 入库采用“备份—dry-run—明确批次—应用—完整性/外键/FTS 校验—回滚路径”流程；
- 正文原件只保留在本地数据根，不进入 GitHub；公开仓库只提交元数据、manifest、来源地图、规则、测试和不含正文的研究包。

### 3. 证据链与研究包

每个专题使用统一结构：`事件 -> 主张 -> 来源 -> 文档 -> 页 -> 复核状态`。

专题页面至少提供：

- 严格页级来源和导航来源的区分；
- 来源类型、时间、机构、版本和访问路线；
- 页级引用锚点与可复现查询路径；
- 反例/负控制来源，避免把相关材料误判为证明；
- 缺口、争议和“尚不能下结论”的明确标记；
- 可导出的 `packet.json`，供报告、脚注和后续模型复核使用。

### 4. 检索和产品体验

国内页面与海外页面使用同一套交互：专题入口、时间线、来源筛选、页级证据、研究包、检索结果和状态徽章。

检索结果必须显示“为什么命中”：标题、来源、日期、页码、匹配字段、证据层级和复核状态。关键词 FTS 是基线，后续再增加本地向量检索和可选 reranker；任何语义命中都必须回落到页级来源。

### 5. 质量、运维与评估

建立固定回归集，至少覆盖形成、改组、1945 大会、旧政协、李闻、解散、1948、1949 和学术研究史等问题。每轮任务结束必须记录：

- 新增文档/页数和去重数量；
- `navigation_only`、`machine_verified`、`human_verified`、`citation_ready` 的变化；
- 每个专题的严格页级覆盖率；
- FTS 对齐、完整性、外链/本地路径泄漏和正文泄漏检查；
- 仍未闭合的 P0 缺口及下一步最小闭环。

## 阶段计划

### M0：基线和最小闭环（已完成，2026-08-15）

- 完成 1946 旧政协已视觉确认的 9 页 OCR 小批验证和逐页视觉复核；
- 生成页级 manifest，保留来源 SHA、PDF 页、印刷页、图像 SHA、OCR SHA 和人工复核状态；
- 先写入隔离 staging，确认页图、OCR、FTS 和回滚链路；
- 9 页已提升为汇编层 `strict_citation` 页级入口，但不因为汇编 OCR 或页级复核成功就把它提升为独立一手证据；
- 下一阶段转入 M1：每个专题补至少一条独立来源链，并继续关闭 1946 旧政协正式档案缺口。

### M1：九专题 P0 证据闭环（约 2 周）

- 每个专题至少闭合一个“独立来源 + 页级定位 + 可重放引用路径”；
- 优先补齐 1941、1944、1946 和 1948 的独立原件缺口；
- 对 1947 解散材料做对照链，而不是继续单向扩充解散材料；
- 将已确认页接入正式研究包和检索回归集。

### M2：国内资料层扩展（约 2—4 周）

- 通过公开档案、报刊、图书馆目录和已授权的民盟全媒体数据库扩展来源；
- 将 985 高校、中央研究机构和权威期刊的学术研究纳入 `scholarship_context`；
- 建立主题、人物、机构、地点、版本和争议字段；
- 对重复扫描、电子版和 OCR 产物建立 hash 去重与状态替代关系，不删除原始文件。

### M3：产品 parity 和研究工作流（约 2 周）

- 国内/海外专题页面达到同一信息架构；
- 研究包、检索、时间线、页级引用和导出接口统一；
- 完成 36 个以上问题的基准回归，所有结果能落到来源路径；
- 研究者可从一个主张反向追到原件、页码、SHA 和复核记录。

### M4：持续维护

- 每周以 P0/P1 队列驱动一次小批闭环；
- 每月做一次全库审计、来源变更审计和检索回归；
- 新资料先入 staging，经过门禁后才进入正式索引；
- 任何来源失效只标记访问状态和替代路线，不抹掉历史证据链。

## “国内平台可以正式使用”的验收线

达到以下条件才称为国内平台第一版收口：

1. 九个专题都有来源地图、研究包和缺口说明；
2. 每个专题至少有一条独立一手来源链，且页级定位可重放；
3. 研究包中严格证据、汇编/学术背景和导航线索明确分层；
4. 关键页的 OCR、标题、页码和来源经过人工复核，低质量页不会被标为可引用；
5. 正式库 `PRAGMA integrity_check`、外键、页表/FTS 对齐全部通过；
6. 基准问题检索无路径断裂，页面不泄漏本地绝对路径或正文原件；
7. 公开 GitHub 只包含可审计的代码、元数据和规则，原始资料继续本地保管；
8. 对“尚无独立原件”的问题明确显示缺口，而不是用后出汇编填充成确定结论。

## 分工原则

- Codex：统筹范围、审查证据等级、运行门禁、处理正式库写入、验收和收口；
- 本地 PaddleOCR：执行扫描页识别，产出可追踪 OCR 草稿；
- 其他本地 CLI 模型：可做候选发现、去重、字段整理和初步摘要，但不能自行提升证据等级；
- Computer Use：仅在用户已登录且明确授权的资料库中执行可见的下载/查看动作，所有结果先进入 staging；
- 任何模型都不能把 OCR、汇编、镜像或推断当作未经复核的一手原件。

这个路线的终点不是“国内资料越多越好”，而是国内和海外资料都能在同一个研究工作流里被找到、被判断、被引用、被复核，并且清楚知道哪些地方仍然缺证据。
