# 国史馆官方访客预览接入说明

更新时间：2026-08-22

## 目的

正式数据库已经挂载一批国史馆（DRNH）官方访客水印预览。此前它们只能从对应的 DRNH 文档页进入，国内专题研究包看不到这条可用路线。本次通过
`data/domestic/drnh_preview_event_map.json` 将预览按专题回接到研究页和研究包。

当前回接范围：

- 1945 一大相关背景：3 个档案、6 页预览；
- 1946 李闻：1 个档案、1 页预览；
- 1946 拒参国大：1 个档案、2 页预览；
- 1947 非法化/解散：6 个档案、12 页预览。

## 证据边界

访客预览只登记：

- 档号、题名、日期和来源入口；
- 官方查看器显示的页数；
- 当前本地挂载的预览页数；
- `preview_status=local_visitor_preview`。

它不登记或导出：

- 本地绝对路径；
- 正文、OCR 或机器摘要；
- 清洁原件字节；
- 正式 `citation_ready` 状态。

水印/登入锁定预览可以帮助研究者确认档号、页数、形成者视角和页面结构，但不能替代清洁原件，也不能关闭 `primary_evidence_status` 的开放目标。研究包中的预览链接最终回到 `/doc/<doc_key>`，正式引用仍须通过页级 provenance 和人工引用门禁。

## 重新接收清洁原件时

1. 保留现有预览作为版本和访问审计记录，不覆盖或删除；
2. 将获授权文件放入 authorized-original intake 的 incoming 目录；
3. 补充档号、版本关系、保存/复制许可、页码映射和 SHA256；
4. 完成页身份和正文人工复核后，才建立正式页 provenance；
5. 重新运行统一门禁，只有专题主目标的独立原件闭合后才允许升级 `research_ready`。
