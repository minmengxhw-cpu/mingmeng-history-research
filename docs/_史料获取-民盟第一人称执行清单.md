## 二、入库判断规则

1. 本人日记、本人文集原文、本人书信、本组织机关报刊、本组织自编文件汇编，进入“一手正式层”。
2. 回忆录、纪念文章、政协文史资料、后人传记，只进入“参考层”，不能单独支撑结论。
3. 每件材料入库前必须保存来源字段：藏处/书名/报刊名、卷期、日期、页码、获取方式、是否可公开展示。
4. 中文原文不做中译；旧字、繁体、报纸 OCR 只做现代检索友好的校订，同时保留原文图像或原始页码。
5. 与 FRUS / CIA / Wilson / Hoover / HathiTrust / DRNH / NewspaperSG 对位时，优先标注“同日或同事件”的互证关系。

## 四、平台处理流水线

拿到扫描件后按以下顺序处理：

1. 建立来源记录：材料名、藏处、页码、日期、获取方式、展示权限。
2. OCR：报纸影像按栏校；书籍扫描按页校。
3. 文本整理：繁简统一、旧标点规范化，保留原文页码锚点。
4. 入库：生成 `documents`、`pages`、`translations` 或中文原文对应记录。
5. 检索：重建全文索引，加入人物、组织、事件标签。
6. 对位：与境外七源同日/同事件材料建立证据卡片。
7. 导出：生成史料长编 PDF 和资料包 ZIP。
